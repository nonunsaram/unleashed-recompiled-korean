# 번역 카탈로그

이 디렉터리는 v1.0.0 제작에 사용한 최종 한국어 번역 데이터입니다.

- `core-ui-all.json`: 핵심 UI
- `cutscenes-all.json`: 컷씬 자막
- `hint-all.json`: 힌트
- `item-ui-all.json`: 아이템 UI
- `media-room-ending-ui-all.json`: 미디어 룸 및 엔딩 UI
- `skill-ui-all.json`: 스킬 UI
- `stage-ui-all.json`: 스테이지 UI
- `town-dialogue-all.json`: 마을 대사
- `native-ui-ko.json`, `native-ui-display-overrides.json`: 실행 파일 내 UI와 언어 표시
- `achievements-ko.json`, `achievements-source.json`: 도전과제 번역과 위치 정보
- `ui-textures-ko.json`: 이미지 UI 문구
- `review/remaining-ui/native-ui-comparison.json`: 네이티브 UI 원문 대응표

대조와 위치 식별을 위해 일본어/영어 원문 일부와 게임 내부 식별자가 남아 있습니다. 게임 원문의 권리는 각 권리자에게 있으며, 이 저장소는 그 권리를 주장하지 않습니다. 공개·재사용 범위는 [LICENSE.md](../LICENSE.md)를 확인해 주세요.
