## 긴 한글 자막 추가 확인 3개

영문 문제와 별개로 한 줄 폭이 가장 긴 세 사례입니다. 파일상 잘림이 확인된 것은 아니며 실제 화면에서 끝까지 보이는지 확인하기 위한 추천입니다.

| 순서 | 제목 | 확인할 대사 |
|---:|---|---|
| 4 | 첫날밤 | 하지만 이 모습으로 마을을 돌아다니면 좀 눈에 띄겠는데… |
| 42 | 절망과 희망 | 세계를 밤으로 뒤덮어 모든 것을 파멸로 이끈다 |
| 53 | 어려운 이야기는 나중에 | 우리는 잠들지 않고서는 살아갈 수 없다는 것 또한 / 진리입니다 |

총 19개 중 1·4·15·22·35번을 확인했습니다. 4번 첫날밤의 긴 대사도 정상 표시되었으며, 사용자가 이 확인 범위로 배포를 승인했습니다. 전체 영상을 인게임에서 확인했다는 뜻은 아닙니다.

## 파일 검수 결과

- 현재 HMM과 배포 후보의 자막 43개 아카이브 해시 일치를 확인했습니다.
- 번역 목록 610행 중 568행을 실제 DDS·FTE로 문장 재구성했습니다. 나머지 42행은 번역 데이터에서도 빈 항목입니다.
- 사용된 글자 3,167개를 기준 글꼴 그림과 대조했습니다. 누락·다른 글자 연결·글자 칸 밖 잘림은 발견하지 못했습니다.
- 영문·숫자 문구 23개 전체와 가장 긴 자막 12개를 이미지로 직접 확인했습니다. 쉼표 3곳은 임계 밝기 기준 한 픽셀 차이이며 외곽·크기가 같아 글자 깨짐으로 판단하지 않았습니다.
- 모든 재구성 문장은 1~2줄입니다. 글자 칸 폭 합산 최댓값은 770이며 게임 화면의 770픽셀을 뜻하지 않습니다.
- 인접 장면 자막의 중복 보관 22행과 토네이도 전투용 4행은 같은 폴더의 컷신 XML 참조가 없습니다. 글자 그림 검사는 수행했습니다.

## 확인 범위의 한계

이것은 파일·글자·문장 그림 검수입니다. 게임 자체의 화면 배율, 추가 자간, 자막 위치, 최종 줄바꿈·색상 처리를 재현하지 않았습니다. 기존 FCO의 MainColor 끝값은 490개 비어 있지 않은 셀에서 번역 후 문자 수와 일치하지 않으며 원래 설정이 보존되어 있습니다. 이번 수정으로 생긴 현상으로 분류하지 않았고, 해당 필드가 화면에 미치는 영향은 파일 그림만으로 단정하지 않습니다. 실제 확인 시 문장 끝의 색상이나 누락도 함께 확인해 주세요.

갤러리의 68개 영상 중 이번 한국어 자막 데이터와 연결되는 영상은 42개입니다. 나머지 영상까지 직접 재생해 확인했다는 뜻은 아닙니다. 토네이도 전투 자막 4행도 별도로 검사했습니다.

검수 중 추가 게임 파일 수정은 없었습니다. 이후 사용자가 Fantastic!, OK, Buddy! 및 첫날밤의 긴 대사를 추가 확인하고 동일 버전 1.0.2 수정 배포와 GitHub 업로드를 승인했습니다.
