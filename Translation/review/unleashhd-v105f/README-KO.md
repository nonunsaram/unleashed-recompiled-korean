# 한국어 UI 두 해상도 운영안 — 1.0.5-review6

## 결정

번역 문구와 게임 데이터는 한 벌로 유지하고, 한국어 이미지 자료만 HMM 옵션에서 선택합니다. `기본 UI (720p용)`은 게임 원본 크기의 UI를 사용합니다. `UnleasHD UI (1440p용)`은 UnleasHD 1.4.2를 설치한 경우에만 선택하며 한국어 글자·HUD·상점·타이틀·월드맵·컷신 이미지를 HD 경로에서 먼저 공급합니다. 옵션은 화면 해상도 자체를 변경하지 않습니다. 두 개의 완전한 모드를 따로 관리하면 번역 수정과 DLC 선택이 서로 어긋날 수 있어 한 모드의 두 이미지 프로필로 운영합니다.

## 이번 시험본에 반영한 HD 한국어 이미지

- 일반 대사 한국어 글자 아틀라스 106장: 14개 아카이브에 공통 원본 8장을 복제한 구조입니다. 원본 512×512 페이지 8장을 기존 생성 코드와 글꼴로 바이트 단위까지 동일하게 재현한 뒤, 동일한 UV 배치로 1024×1024 이미지를 다시 그렸습니다.
- 월드맵 한국어 글자 7장: DLC별 월드맵 아카이브 7종에 있던 원본 49장은 위 공통 원본 7장과 바이트 단위로 동일합니다. HD 선택 경로의 `+WorldMap`에 7장을 추가했습니다. 기존 월드맵 HD UI 2장은 보존했습니다.
- 컷신 한국어 자막 46장: 42개 컷신의 자막 44장과 테일즈 이벤트 자막 2장입니다. 컷신 일반 자막은 3,120개의 원본 글자 모양을 대조해, 원본 글꼴과 충분히 일치하는 글자 3,017개(한글 2,905개)를 1024×1024에 다시 그렸습니다. 일치하지 않는 영문·기호 103개는 형태가 바뀌지 않게 원본에서 확대 보존했습니다. 테일즈 자막은 일반 언어 경로와 컷신 전용 경로 두 곳에 HD 이미지를 넣었습니다.
- 타이틀 언어 선택의 한국어 이미지 한 장을 128×256에서 256×512로 다시 그렸습니다. 기존 HD HUD·상점·타이틀 자산과 RING ENERGY 선택 파일 수정도 유지했습니다.

## 남은 범위

- 일본어 원본 글자 페이지는 한국어 글꼴 페이지와 별개입니다. UnleasHD 영어 HD 페이지와 FTE 글자 배치가 달라 그대로 교체하지 않았습니다. 이전에 언급한 15개 충돌 페이지를 포함한 이 원본 페이지들은 추후 원래 서체의 윤곽을 보존하는 별도 작업이 필요합니다.
- 컷신의 일본어·영어 원본 페이지 중 한국어 문구가 없는 한 장은 HD 한국어 재생성 대상에서 제외했습니다.
- 아카이브 왕복 추출, 이미지 크기, 내용 해시, 기본 720p 데이터 보존을 검사했습니다. 게임 화면의 표시·우선순위와 DLC별 월드맵은 아직 플레이 검증이 필요합니다.

## 플레이 확인 순서

1. HMM에서 한국어 패치를 UnleasHD보다 위에 놓고 `한국어 UI 해상도`를 `UnleasHD UI (1440p용)`으로 선택한 뒤 저장하고 게임을 다시 시작합니다.
2. HUD `RING ENERGY`, 상점 구매·판매, 새 게임·이어하기, 언어 선택 화면을 확인합니다.
3. 마을 대사, 월드맵의 지명·문구, 일반 컷신과 테일즈 이벤트 자막을 확인합니다.
4. 필요하면 `기본 UI (720p용)`으로 바꿔 같은 장소의 한국어 문구와 배치를 비교합니다.

HMM 전체판의 기존 DLC·로고·HD 선택값은 보존했습니다. 직전 설치본은 `Build/HMM-Backup-v105e-20260925/UnleashedKorean`에 백업했습니다. 로컬 시험 ZIP에는 UnleasHD 자산이 포함되어 있으므로 공개 업로드용으로 사용하지 않습니다. 공개 배포 시에는 기본판과, 설치된 UnleasHD에서 필요한 호환 이미지를 생성하는 별도 절차 또는 자산 사용 허락을 준비해야 합니다.
