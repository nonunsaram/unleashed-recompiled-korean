# UnleasHD 1.4.2 검토 4: 게이지 선택과 테일즈 자막

## 확인한 원인

- `RING ENERGY` 글자는 `+Sonic/mat_playscreen_en_003.dds`에 있습니다. 기존 한국어 아카이브에는 게임 원본과 바이트가 같은 256×16 이미지가 들어 있었고, 선택된 UnleasHD `BoostGauge/ringenergy`에는 512×32 이미지가 있습니다.
- 한국어 아카이브가 먼저 읽히므로 기존 복사본이 UnleasHD의 게이지 선택 파일을 가렸습니다. 한국어 복사본만 제거했습니다. UnleasHD를 끄면 게임 원본이 사용됩니다. 선택 가능한 `boostenergy` 경로도 같은 이름의 HD 파일을 제공합니다.
- 상점 `구매`·`판매`와 타이틀 `새 게임`·`이어하기`는 앞선 1.0.5-review3 호환 레이어에 이미 HD 한국어 텍스처로 들어 있었습니다. 상점 페이지는 512×256, 타이틀 페이지는 512×1024입니다. review3에서 우선순위를 고쳐 실제로 표시되기 시작했습니다.

## 추가한 테일즈 이벤트 자막 2장

- `evex_ex00_event_000.dds`, `evex_ex01_event_000.dds`를 원래 한국어 자막 글꼴 `LINESeedKR-Rg.ttf`와 저장된 글자 위치를 사용해 512×512에서 1024×1024로 다시 그렸습니다.
- 같은 글꼴과 위치로 512판을 재생성해 원본과 픽셀 형태를 비교한 결과, 글자별 이진화 IoU 평균이 각각 0.9990, 0.9996이었습니다. 원본 한국어 자막의 모양과 배치를 보존했다는 정적 검사입니다.
- 두 페이지가 들어간 `+ExStageTails_Common` 호환 아카이브의 기존 네 UI 파일은 추출 후 SHA-256이 그대로였습니다. 실제 게임 표시는 아직 확인하지 않았습니다.

## 남은 일본어 글자 페이지 15장

- 이전 보고서의 `한국어 글꼴 아틀라스 15개`라는 이름은 부정확했습니다. 14개 아카이브에 있는 `fte_ConverseMain_000.dds` 14장과 춘난의 `_001.dds` 한 장은 한국어 신규 글꼴이 아니라 일본어 원본 페이지와 바이트가 같은 512×512 이미지입니다.
- 한국어 모드는 일본어판의 FTE 글자표와 이 페이지를 함께 보존합니다. UnleasHD의 영어 HD 그림은 해당 FTE와 글자 위치 및 순서가 달라 그대로 바꾸면 일부 대사 글자가 잘못 표시될 수 있습니다.
- 현재 확보한 글꼴로 같은 글자를 다시 그려도 원본 글꼴과 픽셀 형태가 충분히 일치하지 않았습니다. 이 15장은 임의의 영문 HD 파일이나 단순 확대 이미지로 바꾸지 않고 유지했습니다. 고해상도화를 하려면 일본어 원본 글자의 윤곽과 UV를 보존하는 별도 재작업 및 게임 화면 확인이 필요합니다.

## 설치 및 검증

- HMM 전체판 `UnleashedKorean`에 `1.0.5-review4`를 설치했습니다. 기존 모드 옵션, 로드 순서, 전체판 설치 파일은 유지했습니다. 이전 전체판은 `Build/HMM-Backup-v105c-20260925/UnleashedKorean`에 백업했습니다.
- 204개 파일은 review3 후보와 동일하고, 변경된 6개 파일은 게이지 아카이브 2개, 테일즈 자막 아카이브 2개, `mod.ini`, 안내문입니다.
- 로컬 시험 ZIP은 기본판이며 설치된 전체판과 별개입니다. UnleasHD 자산이 포함되어 공개 배포용이 아닙니다.
- 게임 안에서 RING ENERGY 및 테일즈 이벤트 자막이 선명하게 표시되는지는 아직 플레이 검증이 필요합니다.
