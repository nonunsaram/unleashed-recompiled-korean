# 한국어 UI 기본/HD 프로필 — 1.0.5-review7

## 구조

번역 문구와 게임 데이터는 한 벌로 관리합니다. HMM의 `한국어 UI 해상도` 옵션으로 이미지 프로필만 `기본 UI (720p용)` 또는 `UnleasHD UI (1440p용)`으로 고릅니다. 이 옵션은 화면 해상도를 바꾸지 않습니다. 기본 프로필은 게임 원본 크기의 한국어 자산을 사용하고, HD 프로필은 선택된 UnleasHD 1.4.2의 이미지와 같은 크기의 한국어 자산을 먼저 읽습니다. 두 개의 독립 모드로 번역 파일을 중복 유지하지 않습니다.

## HD 프로필의 한국어 이미지

- HUD·상점·타이틀 등 기존 고해상도 한국어 UI와 게이지 선택 파일 우선순위 수정
- 일반 대사 글자 아틀라스 106장: 공통 원본 8장을 14개 아카이브에서 사용. 기존 512×512 이미지를 바이트 단위로 재현한 뒤 같은 글자 좌표로 1024×1024에 재생성
- 월드맵 한국어 글자 7장: DLC별 원본 49장이 공통 원본 7장과 동일한 것을 확인하고 HD 선택 경로에 1024×1024 이미지 추가. 기존 HD 월드맵 UI 2장 보존
- 컷신 한국어 자막 46장: 일반 컷신 44장, 테일즈 이벤트 2장. 일반 컷신 한글 2,905자는 원본 글꼴과 좌표에 맞춰 새로 그림. 원본과 일치하지 않는 영문·기호 103자는 모양을 보존해 확대. 테일즈 자막은 일반 언어 경로와 컷신 전용 경로 모두에 HD 이미지 배치
- 타이틀 언어 선택 한국어 이미지 1장을 256×512로 재생성
- 대화 이름표 `소닉·테일즈·칩`을 UnleasHD 512×512 원본 위에 다시 그림. 이름 영역 밖의 HD 픽셀은 유지

## 아직 남은 부분

일본어 원본 글자 페이지는 기존 FTE 글자 배치를 보존하기 위해 512×512로 남겨뒀습니다. UnleasHD의 영어 HD 페이지를 대입하면 글자가 달라질 수 있습니다. 번역 글자가 없는 컷신 원본 페이지 한 장도 한국어 HD 재생성 범위에서 제외했습니다.

아카이브 추출·재포장, 분할 파일 수, 이미지 크기, 해시, 기본 720p 파일 보존, HMM 옵션과 모드 순서를 정적으로 확인했습니다. 실제 게임 화면과 DLC별 월드맵의 적용 순서는 아직 플레이 검증 전입니다.

## 확인할 화면

1. HMM에서 한국어 패치를 UnleasHD보다 위에 놓고 `한국어 UI 해상도`를 `UnleasHD UI (1440p용)`으로 선택해 저장합니다. 게임을 완전히 다시 시작합니다.
2. HUD의 `RING ENERGY`, 상점 구매·판매, 타이틀 새 게임·이어하기와 언어 선택을 확인합니다.
3. 대화 상대 이름표, 마을 대사, 월드맵 문구, 일반 컷신과 테일즈 이벤트 자막을 확인합니다.
4. `기본 UI (720p용)`으로 전환해 같은 장소에서 글자 위치와 번역이 동일한지도 확인할 수 있습니다.

현재 HMM 전체판은 `1.0.5-review7`이며 기존 HD 선택값, DLC 선택, 로고 선택을 보존했습니다. 직전 설치본은 `Build/HMM-Backup-v105f-20260925/UnleashedKorean`에 백업했습니다. 로컬 시험 ZIP에는 UnleasHD 자산이 들어 있어 공개 업로드용이 아닙니다. 공개 배포 전에 HD 자산 사용 허락을 받거나, 설치된 UnleasHD에서 호환 파일을 사용자 로컬에서 생성하는 절차가 필요합니다.
