# 1.0.5 인명 표기 대조

기존 `Translation/*-all.json` 8개 카탈로그(11,912개 고유 번역 항목)를 검색하고, `core-ui-all.json`의 `name_tag` 113건과 기존 용어집의 인물 관련 38건을 일본어·영어·한국어로 대조했습니다. 전 항목의 수동 의미 재번역을 완료했다는 뜻은 아닙니다. 대조 결과 전체는 `name-tags-113.csv`와 `glossary-people-38.csv`에 있습니다. `character-voices.json`은 말투 기준이므로 이름의 1차 목록으로 사용하지 않았습니다.

## 확정 수정: 춘난의 왕 씨

- 일본어 `ワン`, 영어 `Wang`, 기존 한국어 `완` → `왕`.
- 이름표 2건, 아이템 3건, 미디어룸 2건의 고유 번역 항목 7건을 수정했습니다.
- 이 7개 항목이 게임 리소스에서 반복된 70개 물리 셀을 20개 아카이브에서 수정하고, 모든 아카이브의 비대상 셀과 파일을 보존하며 왕복 검증했습니다. 기본 월드맵과 DLC 선택별 월드맵도 포함됩니다.
- 자세한 키·위치·전후 문구는 `wang-edits.json`, 아카이브 검증은 `resource-verification.json`에 있습니다. 과거 `astra-final/fixes.json`의 `왕→완` 기록은 당시 작업 이력으로 두고, 이 결정이 최신 표기 기준입니다.

## 등장 지역과 추천

이름표 113건의 등장 지역과 추천 표기는 `name-regions-113.csv`에, 검토 이력 14건(조세프 유지 확정, 나머지 13건)의 근거는 `regional-recommendations-KO.md`에 정리했습니다. 인물의 실제 국적은 게임 데이터에서 확인되지 않았습니다. 현재 추가 변경을 추천하는 표기는 `일마→이르마`, `이포리타→이폴리타`이며 아직 게임 파일에는 적용하지 않았습니다. `조세프`는 사용자 결정에 따라 유지합니다.
