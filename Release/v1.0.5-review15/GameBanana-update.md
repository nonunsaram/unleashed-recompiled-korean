# v1.0.5-review15 — 한국어 UI HD 호환·이름 표기·오프닝 로고 수정

이번 검토본은 UnleasHD 1.4.2의 **1440p판**과 함께 사용할 때 한국어 HUD·상점·월드맵·대사 글자·컷신 자막을 HD 선택 경로에서 읽도록 개선했습니다. 한국어 패치를 UnleasHD보다 위에 놓고, 한국어 패치 설정에서 **UnleasHD UI (1440p용)**을 선택해 저장한 다음 게임을 다시 시작해 주세요. 다른 UnleasHD 해상도판에는 적용하지 마세요.

춘난 상점 주인은 **왕**, 스파고니아의 두 인물은 **이르마·이폴리타**로 표기를 통일했습니다. 스카이스크레이퍼 스캠퍼 밤 Act 2의 월드맵 미리보기를 수정했고, 한국어 타이틀 로고를 선택하면 오프닝에도 같은 디자인이 나옵니다. 소닉 월드 어드벤처 오프닝 로고의 잘린 흰 윤곽과 지구 왼쪽 윤곽도 다듬었습니다.

기본판과 전체판 중 하나만 설치하세요. 전체판의 EXE 한국어화 내용은 1.0.4와 같습니다. 15개의 일본어 원본 글자 페이지는 기존 크기를 유지하며, 실제 게임의 모든 장면은 아직 플레이 검증 전입니다. 자세한 내용은 `CHANGELOG-KO.md`를 참고해 주세요.

**게시 상태:** 이 문서는 게시문 초안입니다. HD 호환 파일의 공개 배포 조건이 확인되기 전에는 review15 로컬 시험 ZIP을 업로드하지 않습니다.
