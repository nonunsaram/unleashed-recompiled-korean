# 한국어 패치 v1.0.4

2026-09-16 · Unleashed Recompiled v1.0.3 Windows x64용

- 프랑사랑단 님이 재작업한 ‘소닉 언리쉬드’ 한국어 로고를 추가했습니다.
- 로고 바깥의 불필요한 잔여 픽셀을 정리하고, 크기와 흰색 외곽 광선을 조정했습니다.
- 영어·일본어 원본 형태와 한국어 추가 형태, 총 네 가지 선택형 로고에 고해상도 타이틀 자료를 적용했습니다.
- ‘게임 기본값’은 로고를 덮어쓰지 않습니다. 다른 로고 모드가 있으면 해당 모드를 따르고, 없으면 게임 원본을 사용합니다.
- 소닉 월드 어드벤처의 기존 광선 확대·복귀 연출을 유지했습니다.

UnleasHD를 별도로 설치하지 않아도 네 가지 선택형 로고는 고해상도로 표시됩니다. 소닉 월드 어드벤처의 작은 한국어 문구는 기존 제공 이미지를 확대하여 사용합니다. 1.0.3의 번역·자막·EXE UI 수정은 그대로 포함됩니다.
