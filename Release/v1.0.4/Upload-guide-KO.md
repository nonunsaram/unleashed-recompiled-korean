# GameBanana v1.0.4 업로드 안내

이번 최종 후보는 `outputs/GameBanana-1.0.4-FinalCandidate`에 있습니다. 앞서 만든 `outputs/GameBanana-1.0.4`의 ZIP은 자막 수정이 누락되어 있으므로 업로드하지 마세요. 최종 후보의 체크섬을 기준으로 사용합니다.

기존 한국어 패치 페이지 https://gamebanana.com/mods/715787 에 업데이트합니다.

1. `UnleashedRecompiled-Korean-1.0.4-Basic.zip`과 `UnleashedRecompiled-Korean-1.0.4-Full.zip`을 그대로 업로드합니다.
2. 파일 설명은 각각 `v1.0.4 Basic — HMM 기본판`, `v1.0.4 Full — Basic 포함, EXE UI 추가 한국어화`로 적습니다. Basic을 기본 HMM 원클릭 설치 파일로 지정합니다.
3. 업데이트 제목은 `v1.0.4 — 한국어 로고 추가·타이틀 고해상도 적용`을 사용하고 `GameBanana-update.md`를 본문에 붙여 넣습니다.
4. 메인 소개문은 `GameBanana-post.md`를 사용합니다. 크레딧에 한국어 로고 제작자 **프랑사랑단**, 고해상도 타이틀 제작 **UnleasHD Team**을 표기합니다.
5. 업로드 파일을 다시 내려받아 `SHA256SUMS.txt`와 비교합니다.

GitHub에는 소스·문서·체크섬만 반영합니다. 배포 ZIP은 GameBanana용이며, 이 파일의 생성은 GameBanana 업로드 완료를 의미하지 않습니다.
