# Unleashed Recompiled 한국어 패치 v1.0.4

Unleashed Recompiled v1.0.3 Windows x64용 비공식 한국어 패치입니다. 게임 본편·업데이트·DLC는 포함하지 않습니다.

## 설치

Basic 또는 Full 중 하나를 HMM에 설치하고 활성화하세요. 화면 언어는 **English**, 자막은 **켜기**로 설정합니다. Full에는 Basic 내용과 옵션·도전과제 등 EXE UI 번역 설치 도구가 포함됩니다.

모든 DLC가 설치되어 있다면 기본 설정을 유지하세요. 일부 DLC만 설치했다면 설치한 팩 중 목록의 가장 위 항목을 선택하고, DLC가 없다면 `DLC 없음`을 선택하세요. 이 설정은 DLC를 추가하지 않습니다.

UnleasHD 1.4.2를 함께 사용하면 한국어 패치를 UnleasHD보다 위에 두고 **UnleasHD 호환 → UnleasHD 1.4.2**를 선택하세요. 로고의 고해상도 적용은 이 호환 옵션과 별개입니다.

## 타이틀 로고

HMM 모드 설정에서 다음 다섯 가지 중 선택합니다.

- 게임 기본값: 로고를 덮어쓰지 않음
- 소닉 언리쉬드 (영어 원본)
- 소닉 언리쉬드 (한국어 추가)
- 소닉 월드 어드벤처 (일본어 원본)
- 소닉 월드 어드벤처 (한국어 추가)

게임 기본값 외의 네 가지는 고해상도 로고입니다. 여기서 ‘원본’은 영어·일본어 디자인을 뜻합니다. 기본값은 설치된 로고 모드를 따르며, 다른 모드가 없다면 게임 원본을 사용합니다. 설정을 저장한 뒤 게임을 다시 시작하세요.

## v1.0.4

- 프랑사랑단 님이 재작업한 ‘소닉 언리쉬드’ 한국어 로고를 추가했습니다.
- 로고 바깥의 불필요한 잔여 픽셀을 정리하고, 크기와 흰색 외곽 광선을 조정했습니다.
- 영어·일본어 원본 형태와 한국어 추가 형태, 총 네 가지 선택형 로고에 고해상도 타이틀 자료를 적용했습니다.
- ‘게임 기본값’은 로고를 덮어쓰지 않습니다. 다른 로고 모드가 있으면 해당 모드를 따르고, 없으면 게임 원본을 사용합니다.
- 소닉 월드 어드벤처의 기존 광선 확대·복귀 연출을 유지했습니다.

UnleasHD를 별도로 설치하지 않아도 네 가지 선택형 로고는 고해상도로 표시됩니다. 소닉 월드 어드벤처의 작은 한국어 문구는 기존 제공 이미지를 확대하여 사용합니다. 1.0.3의 번역·자막·EXE UI 수정은 그대로 포함됩니다.

한국어 로고: **프랑사랑단** · 고해상도 타이틀 자료: **UnleasHD Team**.
