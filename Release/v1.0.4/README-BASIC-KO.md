# 한국어 패치 v1.0.4 — Basic

Unleashed Recompiled v1.0.3 Windows x64용입니다. Basic과 Full 중 하나만 설치하세요.

1. Basic ZIP을 HedgeModManager에 설치합니다.
2. 한국어 패치를 체크하고 저장합니다. 이전 한국어 패치는 함께 활성화하지 않습니다.
3. 게임 화면 언어는 **English**, 자막은 **켜기**로 설정합니다. 음성 언어는 자유롭게 선택할 수 있습니다.

Basic은 EXE를 변경하지 않습니다. 이전 Full에서 Basic으로 전환한다면 먼저 Full 설치 도구의 **.exe 원본 복원**을 실행하세요.

모든 DLC가 설치되어 있다면 기본 설정을 유지하세요. 일부 DLC만 설치했다면 설치한 팩 중 목록의 가장 위 항목을 선택하고, DLC가 없다면 `DLC 없음`을 선택하세요. 이 설정은 DLC를 추가하지 않습니다.

UnleasHD 1.4.2를 함께 사용하면 한국어 패치를 UnleasHD보다 위에 두고 **UnleasHD 호환 → UnleasHD 1.4.2**를 선택하세요. 로고의 고해상도 적용은 이 호환 옵션과 별개입니다.

## 타이틀 로고

HMM 모드 설정에서 다음 다섯 가지 중 선택합니다.

- 게임 기본값: 로고를 덮어쓰지 않음
- 소닉 언리쉬드 (영어 원본)
- 소닉 언리쉬드 (한국어 추가)
- 소닉 월드 어드벤처 (일본어 원본)
- 소닉 월드 어드벤처 (한국어 추가)

게임 기본값 외의 네 가지는 고해상도 로고입니다. 여기서 ‘원본’은 영어·일본어 디자인을 뜻합니다. 기본값은 설치된 로고 모드를 따르며, 다른 모드가 없다면 게임 원본을 사용합니다. 설정을 저장한 뒤 게임을 다시 시작하세요.
