# Korean Translation v1.0.4 — Basic

For Unleashed Recompiled v1.0.3, Windows x64. Install only one edition. Set the in-game text language to English and enable subtitles. Voice language can be chosen independently.

The default DLC setting assumes all DLC is installed; choose your installed pack or No DLC otherwise. With UnleasHD 1.4.2, place the Korean patch above it and select the matching compatibility option.

Five title choices are available: Game default, English Sonic Unleashed, Sonic Unleashed with Korean lettering, Japanese Sonic World Adventure, and Sonic World Adventure with Korean lettering. Game default does not override any title resource. The other four choices include HD title textures and do not require a separate UnleasHD installation. The small Korean World Adventure caption is enlarged from its existing source. The original World Adventure halo animation is preserved.

Korean Unleashed logo: 프랑사랑단. HD title textures: UnleasHD Team. See CREDITS.md. Restart the game after changing settings.

Install the Basic ZIP in HedgeModManager, enable the mod and save. Basic does not modify the game executable. Restore the executable using the Full installer before switching from Full to Basic.
