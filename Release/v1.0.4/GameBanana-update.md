# v1.0.4 — 한국어 로고 추가·타이틀 고해상도 적용

- 프랑사랑단 님이 재작업한 ‘소닉 언리쉬드’ 한국어 로고를 추가했습니다.
- 로고 바깥의 불필요한 잔여 픽셀을 정리하고, 크기와 흰색 외곽 광선을 조정했습니다.
- 영어·일본어 원본 형태와 한국어 추가 형태, 총 네 가지 선택형 로고에 고해상도 타이틀 자료를 적용했습니다.
- ‘게임 기본값’은 로고를 덮어쓰지 않습니다. 다른 로고 모드가 있으면 해당 모드를 따르고, 없으면 게임 원본을 사용합니다.
- 소닉 월드 어드벤처의 기존 광선 확대·복귀 연출을 유지했습니다.

UnleasHD를 별도로 설치하지 않아도 네 가지 선택형 로고는 고해상도로 표시됩니다. 소닉 월드 어드벤처의 작은 한국어 문구는 기존 제공 이미지를 확대하여 사용합니다. 1.0.3의 번역·자막·EXE UI 수정은 그대로 포함됩니다.

한국어 로고를 재작업해 주신 **프랑사랑단** 님과 고해상도 자료를 제작한 **UnleasHD Team**에 감사드립니다.

Basic과 Full 중 하나만 설치하세요. 기존 1.0.3 사용자는 같은 판으로 교체하면 됩니다. Full의 EXE 번역 내용은 1.0.3과 같으며, 이미 적용했다면 다시 적용할 필요가 없습니다.


## 최종 검토 수정 — 2026-09-16

1.0.3부터 빠졌던 영문 자막 기준선 수정을 복구했습니다. `Excellent!`, `Dr.` 등이 포함된 컷신 16개 묶음에, 사용자가 1.0.2에서 정상 표시를 확인한 자막을 다시 반영했습니다. 이후 대사·줄바꿈 수정과 고해상도 로고는 유지됩니다.

최종 1.0.2 배포본에 이후 승인된 변경을 더한 기준과 모든 배포 리소스를 대조하며, 이전 수정이 누락되면 패키징을 중단합니다. 버전은 1.0.4, 개정 식별자는 `20260916-final-audit`입니다.
