# 그래픽 모드와 함께 사용하기

HMM의 위에서 아래 순서로 한국어 패치를 가장 위에 두세요.

1. Korean Translation / 한국어 패치
2. UnleasHD (1440p)
3. Sonic Unleashed Visual Overhaul – Characters
4. High Resolution Textures

UnleasHD 1.4.2를 사용하면 한국어 패치의 설정에서 **UnleasHD 호환 → UnleasHD 1.4.2**를 선택하세요. 저장한 뒤 게임을 완전히 종료하고 다시 실행합니다. UnleasHD의 타이틀용 고해상도 텍스처 일부를 로고 선택지에 포함하며, 그래픽 모드 전체는 포함하지 않습니다.


‘게임 기본값’은 타이틀 파일을 덮어쓰지 않습니다. 다른 네 로고 선택지는 자체 고해상도 자료를 사용합니다.
