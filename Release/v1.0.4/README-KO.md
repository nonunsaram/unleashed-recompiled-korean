# 한국어 패치 v1.0.4 — Full

Unleashed Recompiled v1.0.3 Windows x64용입니다. Full에 Basic 내용이 모두 들어 있으므로 둘을 함께 설치하지 마세요.

1. 게임을 한 번 실행해 초기 설정을 완료합니다.
2. Full ZIP을 HMM에 설치하고 게임을 종료합니다.
3. 모드 폴더의 `KoreanFullSetup.exe`에서 `UnleashedRecomp.exe`를 선택하고 **.exe 한국어화 적용**을 누릅니다.
4. HMM에서 한국어 패치를 체크하고 저장합니다. 화면 언어는 **English**, 자막은 **켜기**로 설정합니다.

1.0.3 Full의 EXE 한국어화를 이미 적용했다면 다시 적용할 필요가 없습니다. 제거하거나 Basic으로 전환할 때는 **.exe 원본 복원**을 먼저 실행하세요. `korean-native-backup` 폴더는 복원에 필요합니다.

모든 DLC가 설치되어 있다면 기본 설정을 유지하세요. 일부 DLC만 설치했다면 설치한 팩 중 목록의 가장 위 항목을 선택하고, DLC가 없다면 `DLC 없음`을 선택하세요. 이 설정은 DLC를 추가하지 않습니다.

UnleasHD 1.4.2를 함께 사용하면 한국어 패치를 UnleasHD보다 위에 두고 **UnleasHD 호환 → UnleasHD 1.4.2**를 선택하세요. 로고의 고해상도 적용은 이 호환 옵션과 별개입니다.

## 타이틀 로고

HMM 모드 설정에서 다음 다섯 가지 중 선택합니다.

- 게임 기본값: 로고를 덮어쓰지 않음
- 소닉 언리쉬드 (영어 원본)
- 소닉 언리쉬드 (한국어 추가)
- 소닉 월드 어드벤처 (일본어 원본)
- 소닉 월드 어드벤처 (한국어 추가)

게임 기본값 외의 네 가지는 고해상도 로고입니다. 여기서 ‘원본’은 영어·일본어 디자인을 뜻합니다. 기본값은 설치된 로고 모드를 따르며, 다른 모드가 없다면 게임 원본을 사용합니다. 설정을 저장한 뒤 게임을 다시 시작하세요.
