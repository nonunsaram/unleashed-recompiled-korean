# 1.0.4 최종 후보 점검 결과

2026-09-16 · 개정 식별자 `20260916-final-audit`

**확인된 영문 자막 회귀를 복구했고, 아래에 명시한 검사 범위에서 추가로 설명되지 않는 리소스 변경은 발견하지 못했습니다.** 현재 HMM 설치본도 이 후보와 일치하도록 교체했습니다. 로고·DLC·UnleasHD 호환 설정과 모드 순서는 유지했으며 게임 EXE는 바꾸지 않았습니다. 사용자가 복구 후 인게임 표시가 정상임을 확인했습니다. 이 개정의 소스·문서·체크섬은 GitHub에 반영하며, GameBanana 파일 교체는 사용자가 진행합니다.

## 발견한 문제와 수정

1. **영문 자막 기준선 수정 누락:** 최종 1.0.2에 별도 반영했던 수정이 오래된 개발 폴더에 없었습니다. 1.0.3이 그 폴더를 기반으로 만들어졌고 1.0.4에도 이어졌습니다. `Excellent!`, `Dr.` 등을 포함한 16개 컷신 아카이브를 사용자가 정상 확인한 수정본으로 복구했습니다. 아카이브 목록 파일을 포함한 32개 파일이 승인된 해시와 일치합니다.
2. **Full 소스 묶음의 검증 코드 의존 파일 누락:** `.cjs` 코드와 연결된 두 모듈·검수 입력을 포함하도록 보완했습니다. 공개용 소스로 11,912개 번역 항목에 검수 단계를 다시 적용해도 내용이 유지되는지 확인했습니다. 원본 게임·일부 빌드 중간 입력은 원래부터 공개 대상이 아니므로, 공개 소스만으로 완전 재생성되는 빌드라는 뜻은 아닙니다.
3. **재발 방지 검사 부재:** 이제 최종 1.0.2 배포본의 해시를 고정하고, 승인된 1.0.3 번역 변경과 1.0.4 로고만 더해 전체 리소스를 대조합니다. 문제가 있던 옛 1.0.4를 넣으면 자막 16개 누락으로 실제 실패하는 것도 확인했습니다.

앞서 만든 1.0.4 Basic과 새 후보를 파일별로 비교했을 때, 게임 리소스 차이는 복구한 자막 아카이브 16개뿐입니다. 고해상도 로고, 광선 연출, 이후 대사·줄바꿈·돈 파치오·STRENGTH 수정은 유지됩니다.

## 남아 있는 제한 사항

- **실제 게임의 모든 장면·분기·해상도·모드 조합을 플레이한 검사는 아닙니다.** 이번에는 파일 전체를 검사했으며 11,912개 문장의 의미를 처음부터 모두 다시 번역·수동 검수하지는 않았습니다. 컷신 미리보기는 실제 DDS 글자를 조합한 것으로 게임의 화면 배치·연출을 재현하지 않습니다.
- `Confirm/ChangeDisk` 관련 **8개 원본 셀**은 이전 검수에서 일부 글리프를 복원하지 못해 원본을 보존하기로 한 부분입니다. 두 실제 FCO 파일이 원본 바이너리와 동일한지 다시 확인했습니다. 정상 번역 완료 또는 실제 미사용이라고 단정하지 않습니다.
- 숫자 치환용 원본 명령 210곳은 글자 누락과 구분해 보존했습니다. 공용 컨트롤러 아이콘의 외부 텍스처 참조 138곳도 모드 내부 DDS 누락과 구분했습니다. 모든 버튼 안내의 실제 게임 표시는 이번 검증 범위에 포함되지 않습니다.
- 쉼표 3개는 기준 그림과 임계값을 넘는 픽셀이 한 개씩 달랐지만, 글자의 경계·기준선·잘림 상태는 같고 정상 확인된 1.0.2에도 동일한 차이가 있습니다. 임의로 다시 그리지 않았습니다.
- 컷신 자막 26개는 해당 묶음 내부 XML에서 직접 호출 위치를 찾지 못했습니다. 이전 검사와 같은 결과이며, 다른 장면에서의 호출 여부를 이번에 새로 확정하지 않았습니다.

## 사용자 인게임 확인

현재 HMM 설치본은 복구한 최종 수정본입니다. `Dr. 에그맨`과 `Excellent!`의 복구 확인을 안내한 뒤 사용자가 “잘나와”라고 정상 표시를 확인했습니다. 이 확인을 모든 게임 장면의 플레이 검증으로 확대하지 않습니다. 로고와 다른 대사는 파일 수준에서 기존 승인본을 유지합니다.

**앞서 만든 `outputs/GameBanana-1.0.4`의 ZIP은 사용하지 마세요.** 최종 후보는 `outputs/GameBanana-1.0.4-FinalCandidate`에 있습니다. Basic·Full 중 하나만 사용합니다. 두 ZIP의 체크섬은 같은 폴더의 `SHA256SUMS.txt`를 기준으로 합니다.
