# v1.0.1 패치노트

## 번역 수정

- 도전과제 12곳과 옵션 설명 2곳의 `웨어호그`를 **웨어혹**으로 수정했습니다. `웨어혹으로` 등 조사도 함께 바로잡았습니다. 전체 번역 카탈로그에서 동일 오표기가 남아 있는지 확인했습니다. 네이티브 글꼴에 없던 `혹` 글자도 추가했습니다.
- 일본어판에서 칩이 자신을 `チップ`이라고 부르는 대사는 **칩**으로 옮기도록 변경했습니다. 컷씬 13항목, 힌트·필드 대사 20항목을 수정했으며 여러 지역에 중복 수록된 대사에도 적용했습니다. 이름을 얻기 전의 대사나 원문에서 이름을 쓰지 않는 자기 지칭까지 일괄 변경하지 않았습니다.
- 소닉의 영어 표현을 다시 점검했습니다. `Fantastic!`, `Excellent!`, `OK`, `OK, Buddy!`는 유지하고, ‘No Reason’ 장면에서 `이봐!`로 번역되어 있던 **Hey!** 한 곳을 수정했습니다. 해당 대사의 잘못된 화자 연결도 원본 자막·음성 시점을 대조하여 바로잡았습니다.

## Full 설치·복원 개선

- 도전과제 번역을 Windows EXE로 옮겼습니다. 새 Full 설치기는 **`patched/default.xex`를 검사하거나 수정하지 않습니다.** 지원되는 지역판·디지털판의 XEX 해시 차이 때문에 한국어 설치가 거부되던 제약을 제거했습니다.
- 대상 Windows EXE는 계속 **공식 Unleashed Recompiled v1.0.3 Windows x64**입니다. XEX 검사 제거가 모든 버전·개인 빌드의 EXE 지원을 뜻하지는 않습니다.
- `portable.txt`가 있으면 게임 폴더, 없으면 `%APPDATA%\UnleashedRecomp\config.toml`을 확인합니다. 게임을 이미 실행했는데도 게임 폴더에서만 설정 파일을 찾아 실패하던 문제를 수정했습니다.
- 설정 파일이 실제로 없으면 게임 최초 실행 → 초기 설정 완료 → 종료 → 설치기 재실행 순서를 안내합니다. **Basic판을 먼저 설치할 필요가 없습니다.** 잘못된 EXE 선택과 잘못된 설정 형식은 별도 메시지로 구분합니다.
- 설치·재설치·복원의 설정 검사는 읽기 전용입니다. 음성 언어, 세이브, 다른 모드 활성화 상태를 보존합니다. 원본 백업 검증, 설치 실패 시 복구, 동시 실행 방지 및 설정·설치 패키지 없이 가능한 EXE 복원을 다시 구현했습니다.

**v1.0.0 Full에서 갱신할 때는 기존 설치기로 먼저 원본 복원한 뒤 새 Full을 설치하세요. 기존 백업을 삭제하지 마세요.**

## 모드 호환성 안내

Denoised / Denoised DLC / Remastered UI와 함께 쓸 때는 HMM에서 **한국어 패치를 이 모드들보다 위에** 두고 저장한 뒤 게임을 완전히 다시 실행하세요. Denoised DLC는 Denoised 본편과 Remastered UI보다 아래에 둡니다. 이것은 Denoised 제작자의 기존 안내에 따른 우선 조치이며, 해당 조합의 해결을 실기 검증했다는 뜻은 아닙니다.

현재 [Denoised 배포 페이지](https://gamebanana.com/mods/531111)는 제작자가 비공개로 전환하여 다운로드할 수 없습니다. 순서를 바꿔도 글자가 깨지면 Denoised DLC를 끄고 비교하세요. 이를 Full 설치기의 오류나 한국어 번역 자체의 결함으로 단정하지 않습니다. 텍스트·글꼴·UI 파일이 겹치는 문제라면 별도 호환 처리가 필요할 수 있습니다.

## 검증 범위

기존 EXE 전용 백엔드의 월드맵·미션 선택 설명·미션 로딩은 사용자 실기 검수에서 정상 확인되었습니다. 이번 번역 수정은 별도로 재생성·직렬화·압축 왕복 검증했습니다. 도전과제 해금 알림은 사용자의 요청으로 추가 실기 검수를 생략하며, 검수 완료로 표시하지 않습니다.
