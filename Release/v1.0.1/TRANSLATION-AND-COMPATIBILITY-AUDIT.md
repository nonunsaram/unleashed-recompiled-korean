# v1.0.1 번역·호환성 후속 검수

검수일: 2026-09-12. 사용자 요청: Denoised DLC 충돌, 웨어혹 표기, 칩 자기 지칭, 소닉 영어 발화, 설치 오류 3건 재확인.

## Denoised DLC

[배포 페이지](https://gamebanana.com/mods/531111)는 실제 브라우저에서 제작자에 의한 비공개 전환 안내가 확인되었다. 열람·다운로드 불가가 단순 사용자 PC 오류라고 볼 수 없다. 사용자가 제시한 버전은 1.0이며 해당 파일을 확보하여 실행한 조합 검증은 하지 못했다.

비공개 안내를 확인하기 전에 조회된 제작자의 기존 설명은 다른 텍스처 모드를 위에 두고, Denoised DLC를 Denoised 본편 및 Remastered UI보다 아래에 두라고 안내한다. 따라서 한국어 모드를 맨 위에 올리고 HMM 저장 후 게임을 재시작하는 것이 첫 조치다. Denoised 본편과 Remastered UI 사이의 순서는 사용 중인 버전의 안내를 따른다.

[v1.0.3 기준 모드 로더](https://github.com/hedge-dev/UnleashedRecomp/blob/cf829a9eca8fb680fba4b0409ddeb6ca92f22e3c/UnleashedRecomp/mod/mod_loader.cpp)는 ActiveMod0부터 읽으며, 일반 파일은 먼저 찾은 경로를 반환한다. `+` 아카이브도 활성 모드 순서대로 처리한다. 한국어 모드는 FCO 텍스트, FTE 글리프 위치와 DDS 글꼴 텍스처를 함께 제공한다. 다른 모드가 일부 파일만 덮으면 영어 복귀 또는 텍스트·글꼴 불일치가 생길 수 있다는 것은 이 구조에 따른 추론이다. 실제 Denoised DLC 파일의 중복 목록이나 결함을 확인한 것으로 표시하지 않는다.

순서 변경으로 해결되면 우선순위 충돌로 볼 수 있다. 계속 깨지면 Denoised DLC만 끄고 비교하고, 이후 실제 파일과 깨지는 화면을 확보했을 때 겹치는 파일을 조사한다. 이때도 고해상도 텍스처 전체를 무조건 제거하거나 다른 모드를 몰래 수정하지 않는다. 이번 배포에는 검증하지 못한 호환 패치를 넣지 않았다.

## 웨어혹

현재 본문 카탈로그 11,912항목, 네이티브 UI 및 도전과제 번역을 검색했다. 오표기는 도전과제 12회, 옵션 설명 2회였다. `웨어혹`으로 통일하며 `웨어호그로`는 `웨어혹으로`로 수정했다. 과거 검수 기록과 원본 백업은 이력으로 유지한다.

도전과제는 새 네이티브 문자열 테이블을 재생성했다. 기존 네이티브 UI의 두 문자열은 .krui의 64바이트 레코드를 검증하고 UTF-8 본문 및 길이 필드만 수정했다. 문자열 주소·코드·글꼴 위치를 이동하지 않으며 새 문자열은 기존 저장 공간보다 길지 않다. 최종 EXE에서 잘못된 표기가 남지 않음을 검사했다.

기존 네이티브 글꼴 6종에는 혹(U+D639)이 없었다. 현재 글꼴 텍스처의 비어 있는 공간에 각 크기·굵기의 혹을 추가하고 글리프 조회·폭 테이블을 갱신했다. 기존 모든 글리프 레코드와 새 타일 밖의 모든 픽셀이 동일함을 검증했다. 최종 EXE가 가리키는 압축 글꼴을 다시 풀어 검증 결과와 비교하고 현재 옵션·도전과제의 모든 글자에 글리프가 존재하는지도 확인했다.

## 칩

D-008을 사용자 결정에 따라 개정했다. 일본어 원문에서 자신의 이름을 말할 때 한국어도 `칩`으로 보존한다. 이름을 얻기 전이나 원문의 대명사를 이름으로 일괄 치환하지 않는다.

컷씬 13항목과 힌트·필드 20항목을 수정했다. 예: `그러면 내가 그 상처를 치유하고` → `그러면 칩이 그 상처를 치유하고`. 같은 항목이 여러 마을에 중복 수록된 경우도 모두 적용했다. 위치별 변경 이력은 `Translation/review/v101/character-edits.json`을 참조한다.

## 소닉 영어 대사

전체 카탈로그 11,912항목에서 일본어의 라틴 문자를 검색하고 컷씬 602항목과 소닉으로 분류된 대사의 문맥을 재검사했다. 컷씬의 라틴 문자 18항목은 `Dr.` 11항목과 영어 발화 7항목이다. 기존에 영어였던 6항목을 보존하고 다음 누락을 수정했다.

| 항목 | 기존 | 수정 | 근거 |
|---|---|---|---|
| evrt_m6_03, cell 41 | 이봐! | Hey! | 일본어 자막 시작 4609프레임 = 음성 J_m6_03_410_es 시작 4609프레임 |

기존 화자 메타데이터는 이 항목을 cue:wh로 연결했다. 원본 음성 리소스의 `es`와 실제 시점을 확인하여 cue:es로 정정했다. 자막 ID와 큐 인덱스만 맞추면 오인할 수 있으므로 일본어 원본 타이밍을 기준으로 삼았다.

`Fantastic!`, `Excellent!`, `OK`, `OK, Buddy!`, 힌트의 `Oh no!`, `What!?`, `Ha!` 등은 영어로 유지된다. `Dr.`, 지명 약어, UI 용어를 소닉의 영어 발화로 세지 않는다. 기존 D-014에 따라 일본어 자막의 가타카나 외래어를 전부 로마자로 바꾸지는 않는다. 이번 검수는 원문 자막과 관련 음성 시점의 검수이며, 모든 음성을 처음부터 끝까지 청취했다고 주장하지 않는다.

## 설치 오류 3건

| 제보 | 새 동작 | 확인 |
|---|---|---|
| patched/default.xex 관련 지원 오류 | manifest와 설치·복원 대상에서 XEX 제외 | XEX 없음·임의 내용·원본 각각 실제 EXE 설치/복원 검사 |
| 이미 실행했는데 config.toml 없음 | portable.txt 유무에 따라 게임 폴더 또는 Windows 사용자 설정 폴더 탐색 | 경로 선택 검사, 설정 누락/손상 시 무수정 중단 |
| config.toml 없으면 Basic 먼저 설치? | Basic 선행 설치 불필요와 최초 실행 절차 안내 | 실제 오류 문자열과 실행 결과 검사 |

Windows v1.0.3 x64 EXE 해시 제한은 유지한다. XEX 제한 제거와 다른 Windows EXE 빌드 지원은 별개다. 실제로 설정 파일이 생성되지 않았거나 다른 계정으로 실행했다면 여전히 설명과 함께 중단하는 것이 정상이다.
