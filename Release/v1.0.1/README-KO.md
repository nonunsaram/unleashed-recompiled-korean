# 한국어 패치 v1.0.1 — Full

Unleashed Recompiled v1.0.3 Windows x64용입니다. Full에는 Basic의 내용이 모두 포함되어 있어 **Basic판을 먼저 설치할 필요가 없습니다.** 두 판을 중복 활성화하지 마세요.

v1.0.1부터 옵션·도전과제 번역은 Windows EXE에서 처리합니다. **`patched/default.xex`는 검사·백업·변경·복원하지 않습니다.** 게임 원본의 지역·디지털판 XEX 해시 차이 때문에 Full 설치가 거부되던 원인을 제거했습니다. 다른 버전·플랫폼·개인 빌드 EXE까지 지원하는 것은 아닙니다.

**기존 v1.0.0 Full 사용자:** 게임을 종료하고 **이전 Full 설치 도구에서 먼저 .exe 원본 복원**을 실행하세요. 그다음 새 Full ZIP으로 교체하고 아래 절차를 따릅니다. 이전 Full은 EXE 외 파일도 변경했기 때문에 새 EXE만 덮어쓰면 과거 변경이 남습니다. 새 도구는 이전 Full EXE를 발견하면 안전한 전환 절차를 안내하고 중단합니다. 이전 설치 도구와 `korean-native-backup`은 전환이 끝날 때까지 보관하세요. Basic만 사용했거나 Full 설치가 파일 검사 단계에서 실패했다면 이 선행 복원은 필요 없습니다.

1. Full판 설치 전에 Unleashed Recompiled를 최소 한 번 실행하여 초기 설정을 완료합니다. 최초 실행 중 `config.toml`이 생성되어야 합니다.
2. Full ZIP을 HedgeModManager(HMM)에 설치합니다.
3. 게임을 종료하고 HMM에서 Full 모드 폴더를 열어 `KoreanFullSetup.exe`를 실행합니다.
4. 게임의 `UnleashedRecomp.exe`를 선택하고 **.exe 한국어화 적용**을 누릅니다. 설치 도구가 EXE의 부모 폴더와 필요한 파일·백업 경로를 자동으로 찾습니다.
5. HMM에서 한국어 패치를 체크하고 저장합니다. 게임의 화면 언어를 **English**, 자막을 **켜기**로 설정합니다. 음성 언어는 원하는 설정을 유지하세요.

`portable.txt`가 EXE 옆에 있으면 설정 파일은 같은 폴더의 `config.toml`입니다. 없으면 Windows 사용자 설정 폴더의 `%APPDATA%\UnleashedRecomp\config.toml`을 자동으로 확인합니다. 설정 파일을 게임 폴더로 복사할 필요는 없습니다.

설정 파일이 없으면 게임 실행 → 초기 설정 완료 → 게임 종료 → 설치 도구 재실행 순서로 진행하세요. 이미 실행했다면 올바른 EXE와 같은 Windows 사용자 계정인지 확인하세요. `[System]`의 `Language` 또는 `Subtitles`가 없거나 지원하지 않는 값이면 설치를 중단합니다. 게임 버전과 설정 파일 상태를 확인하세요. 설치 도구는 새 설정 항목을 삽입하지 않습니다.

설치 도구는 설정을 읽기 전용으로 검사합니다. 설치·재설치·복원 모두 설정 파일 전체와 음성 언어를 그대로 보존합니다. Basic판은 이 설치 도구와 설정 검사를 사용하지 않습니다.

모든 DLC가 설치되어 있으면 HMM 기본 설정을 사용합니다. 일부만 설치했다면 모드 설정에서 설치된 팩 중 목록의 가장 위 항목을 선택하고, DLC가 없으면 `DLC 없음`을 선택하세요.

제거하거나 Basic으로 전환하려면 게임을 종료하고 **.exe 원본 복원**을 실행한 뒤 HMM에서 Full을 해제하세요. 게임 폴더의 `korean-native-backup/Original/UnleashedRecomp.exe`는 복원에 필요합니다. 새 도구는 검증된 원본 EXE를 복원하며, 복원할 때는 `Support`와 `config.toml`이 없어도 됩니다. 게임 폴더를 통째로 이동했어도 백업이 함께 있으면 복원할 수 있습니다. HMM 모드를 유지하면 기본 번역은 유지됩니다.

설치 도구가 중단되면 다시 실행하여 설치 또는 원본 복원을 선택하세요. 백업이 손상되었거나 설치 후 다른 도구가 EXE를 바꿨다면 덮어쓰지 않고 중단합니다. 백업을 삭제하거나 다른 버전의 EXE에 강제로 적용하지 마세요.

## v1.0.1 변경 및 함께 사용하는 모드

칩이 원문에서 자기 이름으로 말하는 대사 33항목을 `칩`으로 수정하고, 소닉의 `Hey!` 한 곳을 영어로 복원했습니다. 지역별 중복 수록분을 포함하여 17개 리소스 묶음의 74개 대사 칸을 수정했습니다. Full에는 도전과제·옵션 설명의 `웨어혹` 표기 수정과 EXE 설치기 개선도 포함됩니다.

Denoised / Denoised DLC / Remastered UI와 함께 쓸 때는 HMM에서 한국어 패치를 이 모드들보다 위에 두고 저장한 뒤 게임을 재시작하세요. Denoised DLC는 Denoised 본편과 Remastered UI보다 아래에 둡니다. 이는 Denoised 제작자의 기존 안내에 따른 우선 조치이며 조합 검증 완료를 뜻하지 않습니다. 순서 변경 후에도 깨지면 Denoised DLC를 끄고 비교하세요. 현재 Denoised 배포 페이지는 제작자가 비공개로 전환하여 파일을 내려받아 검증할 수 없습니다.

Basic은 EXE 설치기나 `config.toml` 검증이 필요 없습니다. Full을 사용할 때도 Basic을 먼저 설치할 필요는 없습니다.
