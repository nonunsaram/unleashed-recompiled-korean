# 한국어 패치 1.0.5-review16 — 전체판 검토본

전체판에는 기본판의 모드 파일이 모두 들어 있으며, 옵션·도전과제 등 EXE UI 한국어화 도구가 추가됩니다. Unleashed Recompiled v1.0.3 Windows x64용입니다. 두 판을 함께 설치하지 마세요.

1. 게임을 한 번 실행해 초기 설정을 완료하고 종료합니다.
2. 전체판 ZIP을 HedgeModManager에 설치합니다.
3. 모드 폴더의 `KoreanFullSetup.exe`에서 `UnleashedRecomp.exe`를 선택하고 **.exe 한국어화 적용**을 누릅니다.
4. HMM에서 한국어 패치를 활성화하고 저장합니다. 게임 화면 언어는 **English**, 자막은 **켜기**로 설정합니다.

이미 1.0.4 전체판의 EXE 한국어화가 정상 적용되어 있다면 같은 패치를 다시 적용할 필요가 없습니다. 제거하거나 기본판으로 바꿀 때는 도구에서 **.exe 원본 복원**을 먼저 실행하고, 복원용 `korean-native-backup` 폴더를 보존하세요.

UnleasHD 1.4.2 **1440p판**을 함께 쓴다면 HMM에서 한국어 패치를 UnleasHD보다 **위**에 놓고 **한국어 UI 해상도 → UnleasHD UI (1440p용)**을 선택한 뒤 저장하고 게임을 다시 시작합니다. DLC와 로고 선택도 실제 설치 내용과 취향에 맞게 설정합니다.

변경 사항과 확인 범위는 `CHANGELOG-KO.md`를 확인하세요. 이 검토본의 HD 파일은 설치된 UnleasHD 자산으로 만들었으며, 공개 배포 조건이 확인되기 전까지 로컬 시험용입니다.

review16은 번역하지 않은 HD 중복 파일을 제외하고 한국어 HD 수정본을 모두 유지합니다. 영어·일본어 원본 로고는 별도 UnleasHD에서 읽으며, 없으면 게임 원본 화질입니다. 수정된 UnleasHD 그림의 공개 배포 허락은 요청 중입니다.
