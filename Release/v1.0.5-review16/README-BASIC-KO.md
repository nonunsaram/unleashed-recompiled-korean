# 한국어 패치 1.0.5-review16 — 기본판 검토본

Unleashed Recompiled v1.0.3 Windows x64용입니다. 대사·자막·월드맵·미션·게임 내 이미지 UI를 한국어화합니다. 게임 EXE의 옵션·도전과제 UI도 한국어화하려면 전체판을 사용하세요. 기본판과 전체판은 하나만 설치합니다.

1. ZIP을 HedgeModManager에 추가하고 한국어 패치를 활성화합니다.
2. 게임의 화면 언어를 **English**, 자막을 **켜기**로 설정합니다. 음성 언어는 자유롭게 선택할 수 있습니다.
3. 모든 DLC가 설치되어 있지 않다면 한국어 패치 설정에서 실제 설치한 DLC에 맞는 항목을 선택합니다.
4. UnleasHD 1.4.2 **1440p판**을 함께 쓴다면 한국어 패치를 UnleasHD보다 **위**에 놓고, **한국어 UI 해상도 → UnleasHD UI (1440p용)**을 선택합니다. HMM에서 저장하고 게임을 완전히 다시 시작합니다. UnleasHD를 사용하지 않으면 **기본 UI (720p용)**을 유지합니다.

타이틀·오프닝 로고는 같은 설정을 따릅니다. **게임 기본값**은 다른 로고 자료를 덮어쓰지 않습니다. 한국어 추가 두 가지를 선택하면 해당 디자인의 한국어 타이틀과 오프닝 로고가 함께 적용됩니다.

변경 사항과 확인 범위는 `CHANGELOG-KO.md`를 확인하세요. 이 검토본에 포함된 UnleasHD 파생 그림 중 UI 호환 파일(HUD·상점·월드맵·대화 이름표·DLC 미리보기)은 UnleasHD 1.4.2(1440p), 한국어 추가 타이틀 로고와 발광 이미지는 UnleasHD 4K 저장소 자료(리비전 c7a70974)를 바탕으로 만들었습니다. 공개 배포 조건이 확인되기 전까지 로컬 시험용입니다.

review16은 번역하지 않은 HD 중복 파일을 제외하고 한국어 HD 수정본을 모두 유지합니다. 영어·일본어 원본 로고는 별도 UnleasHD에서 읽으며, 없으면 게임 원본 화질입니다. 수정된 UnleasHD 그림의 공개 배포 허락은 요청 중입니다.
