# 1.0.5-review16 게시 준비 상태

기본판·전체판의 로컬 후보 ZIP을 파일 목록·해시·압축 무결성 기준으로 검사할 수 있습니다. **현재 후보를 GameBanana나 GitHub 릴리스 자산으로 업로드하지 마세요.** HD 호환 폴더의 UI 파일은 UnleasHD 1.4.2(1440p), 한국어 추가 타이틀 로고는 UnleasHD 4K 저장소 자료(리비전 c7a70974)를 바탕으로 만들어졌으며, 공개 재배포 허락 또는 사용자 PC에서 생성하는 별도 절차가 아직 확인되지 않았습니다.

GameBanana 기존 페이지는 <https://gamebanana.com/mods/715787>입니다. 게시 가능 상태가 되면 기본판을 HMM 기본 설치 파일로, 전체판을 EXE UI 추가 한국어화용으로 안내하고 `GameBanana-update.md`의 게시 상태 문구를 갱신합니다. 두 판 중 하나만 설치하도록 명시합니다.

GitHub 공개 소스에는 게임·DLC·설치된 UnleasHD 자산과 배포 ZIP을 넣지 않습니다. 정적 검사와 실제 게임 화면 확인은 구분해 적습니다.
