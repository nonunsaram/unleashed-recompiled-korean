# 한국어 패치 1.0.5-review16 변경 사항

2026-09-26 · Unleashed Recompiled v1.0.3 Windows x64용 검토본

## review15에서 review16으로 바뀐 점

- 번역하지 않은 UnleasHD UI 복사본 28개와 영어·일본어 원본 타이틀 로고 복사본 4개를 제외했습니다. 중복 경로의 파일은 각각 셌습니다.
- 같은 UI를 가리던 무수정 게임 원본 복사본 28개도 제외했습니다. UnleasHD가 있으면 아래 모드의 HD 이미지, 없으면 게임 원본 이미지를 사용합니다.
- **한국어 HD 수정본은 모두 보존했습니다.** HUD·상점·미디어룸·월드맵·이름표·한국어 추가 타이틀 로고와 글꼴·자막·오프닝은 review15와 바이트 단위로 동일합니다.
- 영어·일본어 원본 로고는 아래 모드에서 읽습니다. 설치된 1440p판의 로고 시트는 2048×1024, 발광 시트는 1280×1280입니다. 한국어 추가 두 로고의 기존 수정본은 바꾸지 않았습니다.
- **월드맵 DLC 미리보기 수정본 제외:** 엠파이어 시티 스카이스크레이퍼 스캠퍼 밤 Act 2 미리보기 수정은 UnleasHD 쪽 표시라서 이번 버전에서 제외했습니다. HD 프로필에서는 아래 UnleasHD의 원본 미리보기가 표시됩니다.
- 설치된 HD 모드의 공급 파일 32개, DLC 7가지×로고 5가지의 파일 선택 조합, 아카이브 왕복과 모든 보존 리소스의 해시를 확인했습니다. 실제 게임의 모든 화면을 플레이 검증한 결과는 아닙니다.

## 1.0.4에서 달라진 점

- **한국어 UI 해상도 선택:** 기본 UI(720p용)와 UnleasHD 1.4.2(1440p용) 프로필을 분리했습니다. HD 프로필에는 HUD·결과 화면·상점·타이틀·월드맵의 겹치는 UI와 한국어 글자·컷신 자막을 고해상도로 준비했습니다. 화면 출력 해상도 자체를 바꾸는 설정은 아닙니다.
- **HD 표시 우선순위:** 한국어 패치를 UnleasHD 위에 놓았을 때 HD 호환 파일이 기본 한국어 이미지보다 먼저 읽히도록 수정했습니다. `TIME`, `SCORE`, `SPEED`, `RINGS`, `RING ENERGY`, 구매·판매 등의 흐림 문제를 대상으로 합니다.
- **이름 표기:** 춘난 상점 주인의 `완`을 `왕`으로, 스파고니아의 `일마`를 `이르마`로, `이포리타`를 `이폴리타`로 고쳤습니다. 이름표·대사·아이템·미디어룸 설명에 반영했습니다.
- **HD 글자와 자막:** 한국어 글자 페이지 106곳, 월드맵 글자 7장, 컷신 자막 46장을 HD 선택 경로에 넣었습니다. 소닉·테일즈·칩의 이름표도 보완했습니다. 컷신의 영문·숫자·문장부호 기준선과 `Excellent!`, `Dr.` 표시를 조정했습니다.
- **오프닝 로고:** 타이틀에서 한국어 로고를 선택하면 오프닝도 같은 디자인을 따릅니다. 소닉 월드 어드벤처 로고의 겹친 검은 테두리, 원본 가로 비율, 위쪽 흰 윤곽과 지구 왼쪽 윤곽을 손봤습니다. 오프닝 영상 파일 자체는 바꾸지 않았습니다.

## 사용 방법과 확인 범위

HedgeModManager에서 한국어 패치를 UnleasHD보다 위에 놓고, 한국어 패치 설정의 **한국어 UI 해상도 → UnleasHD UI (1440p용)**을 선택한 뒤 저장하고 게임을 완전히 다시 시작합니다. UnleasHD를 사용하지 않으면 **기본 UI (720p용)**을 선택합니다. DLC 선택도 실제 설치 내용에 맞춥니다. 기본판과 전체판 중 하나만 설치합니다. 전체판의 EXE 한국어화 패치는 1.0.4와 동일합니다.

아카이브 왕복, DDS 크기·내용, 설정과 파일 해시를 검사했습니다. 실제 게임의 모든 화면을 플레이 검증한 결과는 아닙니다. 일본어 원본 글자 페이지 15장은 기존 512×512를 유지합니다. 해당 페이지의 실제 사용 여부는 확인되지 않았으므로 모든 UI가 예외 없이 HD라고 단정하지 않습니다.

이 검토본은 UnleasHD 자료를 바탕으로 수정한 HD 파일을 포함합니다. UI 호환 파일(HUD·상점·월드맵·대화 이름표)은 UnleasHD 1.4.2(1440p), 한국어 추가 타이틀 로고 두 종류와 발광 이미지는 UnleasHD 4K 저장소 자료(리비전 c7a709743926a94eb4b9337c54d9abdb103fb8f1)가 바탕입니다. 공개 ZIP 배포에는 해당 자산의 재배포 허락 또는 사용자 PC에서 호환 파일을 생성하는 절차가 필요합니다. 현재 로컬 시험 ZIP을 공개 배포 파일로 올리지 마세요.
