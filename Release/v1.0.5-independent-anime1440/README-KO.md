# Independent Anime 1440p 한국어 패치

**사용자 인게임 테스트 중 / 미게시 후보**입니다. Unleashed Recompiled v1.0.3 Windows x64용이며 기본판과 전체판 중 하나만 설치합니다.

## 제작 방향

한국어 패치에는 **UnleasHD 원본 이미지와 이를 수정한 파생 이미지를 넣지 않습니다.** 게임 원본과 직접 만든 한국어 자료를 사용합니다. 원본 그림에 `realesrgan-x4plus-anime`를 적용하고 한글을 합성했습니다. 월드맵 글자 두 장은 빈 투명 캔버스에서 자체 글꼴로 직접 렌더링합니다.

한국어 UI·이름표·타이틀·발광 20종을 22곳에 배치합니다. 기존 자체 제작 글꼴·컷신 자막·게임 원본 기반 오프닝은 유지합니다. `all-candidates`는 교체 대상 20종이며 모든 글꼴·자막·오프닝을 포함한 목록은 아닙니다. 전체 UI 일괄 확대 실험은 채택하지 않았고 배경·캐릭터·사물은 변경하지 않습니다.

## 설치와 옵션

1. Basic 또는 Full 중 하나를 HMM에 설치합니다. 이전 한국어 패치 및 일괄 UI 확대 테스트 모드는 함께 켜지 않습니다.
2. 게임 화면 언어는 **English**, 자막은 **켜기**로 설정하고 DLC 선택은 실제 설치 내용에 맞춥니다.
3. 별도 UnleasHD 1.4.2 1440p와 함께 쓸 때 HMM에서 **한국어 패치 → UnleasHD** 순서로 놓습니다.
4. **업스케일 한국어 이미지 → 켜기 — 독립 업스케일 / UnleasHD 1440p 호환**을 선택합니다. UnleasHD를 사용하지 않는 기본 구성에서는 **끄기 — 기본 한국어 UI**를 선택합니다.
5. 저장하고 게임을 완전히 다시 실행합니다. 이 옵션은 이미지 공급 경로를 선택하며 화면 출력 해상도를 바꾸지 않습니다.

번역하지 않은 영어 HUD·일반 아이콘은 별도 UnleasHD 또는 게임 원본이 제공합니다. 한국어 타이틀·오프닝 로고는 별도의 로고 항목에서 선택합니다. 독립 제작한 한국어 로고는 1440p 기준이며 기본 UI 옵션에서도 사용할 수 있습니다.

전체판은 기본판에 기존 EXE 한국어화 도구를 추가합니다. 이미 정상 적용된 EXE 패치를 이번 이미지 변경 때문에 다시 적용할 필요는 없습니다. 새로 적용하거나 복원할 때는 게임을 종료하고 기존 설치 도구의 적용·원본 복원 절차를 따릅니다. 복원용 백업을 유지합니다.

## 검증 상태

파일·출처·ZIP 검사와 아카이브 재추출은 완료했습니다. DLC 7 × UI 옵션 2 × 로고 5 = 70개 공급 순서를 검사했습니다. **실제 플레이 품질은 사용자 테스트 중이며 통과로 표시하지 않았습니다.**
