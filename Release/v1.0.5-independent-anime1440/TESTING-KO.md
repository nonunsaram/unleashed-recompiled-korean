# 중점 테스트 화면

상태: 사용자 테스트 중. 아래 항목은 아직 인게임 통과로 기록하지 않았습니다.

HMM 순서 한국어 패치 → UnleasHD, 업스케일 옵션 켜기, 화면 언어 English, 자막 켜기, 실제 DLC 설정을 확인합니다. 설정 변경 후에는 저장하고 게임을 완전히 재시작합니다.

| 우선순위 | 화면 | 확인할 점 |
| --- | --- | --- |
| 1 | 한국어 타이틀 로고 두 종류의 등장·사라짐·발광 | 빛과 로고의 위치 불일치, 한글 어긋남, 사각형 테두리, 잔상·과도한 번짐. 오프닝도 선택한 디자인인지 확인 |
| 2 | 상점 구매·판매, 미디어룸 | 글자 획 뭉침·검은 테두리, 구매/판매·도감·설정 자료집 등의 잘림, 선택 시 겹침 |
| 3 | 소닉·웨어혹 일시정지 및 기술 목록 | 공중·가드 중·대시 중·점프 중 문구와 바탕의 정렬, 행 간격, 메뉴 전환 때 다른 줄이 비치는 현상 |
| 4 | 소닉·테일즈·칩 이름표와 자막 | 이름의 가독성·중앙 정렬·테두리·잘림, 대화/컷신 한글 누락. 글꼴·자막은 보존 자료이므로 주로 적용 충돌 확인 |
| 5 | 월드맵·스테이지 선택·미션 로딩 | 나라·스테이지 이름의 잘림/겹침, 설치한 DLC에 맞는 문구, 소닉·웨어혹 조작 안내의 누락 |
| 6 | 시작·언어 선택·결과/상태 화면 | 작은 한글의 가독성, 일부 문구만 흐린 현상, 선택 표시와 글자 위치 |

## 짧은 확인 순서

한국어 로고 등장 → 마을 대화 → 상점 구매/판매 → 미디어룸 → 낮/밤 일시정지 → 월드맵·미션 로딩 순서로 보면 주요 교체 부위를 확인할 수 있습니다. 테스트를 위해 DLC나 진행 상태를 바꿀 필요는 없습니다.

## 옵션 비교

가능하면 같은 장면을 아래 두 구성으로 비교합니다. 다른 모드 설정은 유지하고 매번 게임을 재시작합니다.

- 호환 구성: 한국어 패치 + UnleasHD 켜기, 업스케일 한국어 이미지 켜기.
- 기본 구성: 한국어 패치 켜기, UnleasHD 끄기, 업스케일 한국어 이미지 끄기.

두 구성 모두 한글이 나와야 합니다. 호환 구성에서는 가장자리와 메뉴 배치가 자연스러운지 봅니다.

## 링 에너지 HUD

영어 RING ENERGY·SPEED·RINGS의 해당 텍스처 두 장은 한국어 패치에 없습니다. 함께 사용하는 UnleasHD가 공급합니다. 이 부분만 동일하게 비뚤어져 보여도 독립 한국어 이미지의 실패로 판단하지 않습니다.

## 문제 기록

화면/장소, 선택한 로고·DLC·업스케일 옵션, 정지 화면인지 전환 중인지와 스크린샷을 알려주세요. 움직일 때만 나타나면 짧은 영상이 도움이 됩니다. 정상 확인한 화면도 알려주시면 검증 범위에 반영합니다.
