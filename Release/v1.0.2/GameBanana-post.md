# Korean Translation / 한국어 패치 v1.0.2

Unleashed Recompiled v1.0.3 Windows x64용 비공식 한국어 패치입니다.

- **Basic:** HMM으로 대사·자막·월드맵·미션 설명·로딩·게임 내 이미지 UI를 한국어로 적용합니다.
- **Full:** Basic 전체 + 옵션·도전과제 등 실행 파일 UI의 한국어화를 포함합니다. HMM 설치 후 모드 폴더의 `KoreanFullSetup.exe`로 추가 적용합니다.

두 판 중 하나만 설치하세요. 게임·DLC·완성된 게임 실행 파일은 포함하지 않습니다.

## 변경 사항

- **타이틀 로고 선택 기능 추가:** 게임 기본값 / 영어판 Unleashed / 일본어판 World Adventure / 한글 문구를 넣은 World Adventure 로고를 선택할 수 있습니다.
- **한글 World Adventure 로고:** 상단 문구를 왼쪽에 배치하고, 원본처럼 글자 획을 따라 퍼지는 흰 외부 광선을 적용했습니다.
- **UnleasHD 1.4.2 호환 옵션 추가:** 함께 사용할 때 월드맵 지명·스테이지명을 한국어로 표시하도록 대응했습니다.
- `에그 드래군` 표기를 `에그 드라군`으로 바로잡았습니다.
- 일부 컷신 자막에서 영문 대소문자가 잘못 표시되던 문제를 수정했습니다. 예: `ExcEllEnt!` → `Excellent!`.

## 그래픽 모드와 함께 사용하기

한패 + UnleasHD 1.4.2 (1440p) + High Resolution Textures 1.4.1 + Visual Overhaul – Characters를 동시에 켠 상태에서 사용자 인게임 테스트를 통과했습니다. 해당 환경의 확인 결과이며 모든 스테이지·설정 조합을 전수 검사한 것은 아닙니다.

HMM의 **위에서 아래로** 다음 순서를 권장합니다. **한국어 패치를 가장 위에 두세요.**

1. **Korean Translation / 한국어 패치**
2. **UnleasHD (1440p)**
3. **Sonic Unleashed Visual Overhaul – Characters**
4. **High Resolution Textures**

UnleasHD를 쓰면 한국어 패치의 톱니바퀴에서 **UnleasHD 호환 → UnleasHD 1.4.2**를 선택하세요. 두 모드의 DLC 옵션은 실제 설치 구성에 맞춰 주세요. 저장 후 게임을 완전히 종료하고 다시 실행합니다.

## 로고 선택

HMM에서 한국어 패치의 톱니바퀴 → **타이틀 로고 → 일본어판 로고 (사용자 편집)**을 선택하면 한글 문구가 들어간 로고가 나옵니다. 기본값은 게임 기본값이며 기존 타이틀 설정을 따릅니다.

## 업데이트 안내

- Basic과 Full 중 하나만 설치하세요. Full에는 Basic의 내용이 모두 포함되어 있습니다.
- 게임 화면 언어는 **English**, 자막은 **켜기**로 설정합니다.
- v1.0.1 Full과 EXE 번역 내용이 같으므로, v1.0.1 Full 사용자는 EXE를 복원하지 않고 업데이트할 수 있습니다.
- v1.0.0 Full에서 바로 업데이트한다면 이전 도구로 원본 복원을 먼저 진행해 주세요.

## 점검 및 범위

갤러리 영상 제목 272칸의 번역 일치를 확인했습니다. 제보된 간헐적 영문 제목 현상은 아직 재현되지 않아 해결 완료로 표기하지 않습니다. 특정 제목이 영어로 보이면 영상 제목과 모드 목록·순서를 함께 알려 주세요.

Visual Overhaul 확인 범위는 **Characters 구성**입니다. Crimson Carnival over Eggmanland와 Windmill Isle Act 5가 별도로 추가하는 액트명은 이번 호환 옵션의 번역 대상이 아닙니다. 그래픽 모드 자체는 한패에 포함되지 않습니다.
