# 그래픽 모드와 한국어 패치 설치 순서

한국어 패치 v1.0.2와 UnleasHD 1.4.2 (1440p), High Resolution Textures 1.4.1, Visual Overhaul – Characters의 동시 사용을 사용자 인게임 테스트로 확인했습니다. 모든 장면의 전수 검증을 뜻하지 않습니다.

## 각 모드의 역할

| 모드 | 주로 바뀌는 부분 |
| --- | --- |
| High Resolution Textures | 배경·사물 등의 표면 그림을 더 좋은 원본으로 교체합니다. 일부 캐릭터 자료도 포함합니다. |
| Visual Overhaul – Characters | 캐릭터의 모델·질감·털 표현 등을 변경합니다. 스테이지 조명까지 바꾸는 전체 구성과 구분됩니다. |
| UnleasHD | 메뉴·HUD·버튼 등의 그림을 더 선명하게 만듭니다. 이번 확인본은 1440p판입니다. |

같은 자료를 바꾸면 우선순위가 높은 모드가 적용됩니다. 모두 켠다고 효과가 계속 더해지는 것은 아니며, 성능과 취향에 맞춰 사용하세요.

## 권장 순서: HMM 위 → 아래

1. **Korean Translation / 한국어 패치**
2. **UnleasHD (1440p)**
3. **Sonic Unleashed Visual Overhaul – Characters**
4. **High Resolution Textures**

**위에 있는 모드가 우선입니다. 한국어 패치를 가장 위에 두세요.** 아래 두 그래픽 모드는 선호하는 캐릭터 표현에 따라 순서를 조절할 수 있습니다.

1. 한국어 패치 설정에서 **UnleasHD 호환 → UnleasHD 1.4.2**를 선택합니다. UnleasHD를 사용하지 않으면 **사용 안 함**을 유지합니다.
2. UnleasHD의 **Do you have DLC?**와 한국어 패치의 DLC 선택을 실제 설치 내용에 맞춥니다.
3. 화면 언어를 **English**, 자막을 **켜기**로 설정합니다.
4. HMM에서 저장하고 게임을 완전히 종료한 뒤 다시 실행합니다.

호환 옵션은 월드맵의 한국어 지명·스테이지명 그림에 대응합니다. UnleasHD의 모든 그림을 고해상도 한국어로 교체한다는 뜻은 아닙니다.

## 로고 선택

한국어 패치 톱니바퀴 → **타이틀 로고**에서 선택합니다.

- 게임 기본값: 게임의 기존 타이틀 설정을 따릅니다.
- 영어판 로고: Sonic Unleashed.
- 일본어판 로고: Sonic World Adventure, 일본어 상단 문구.
- 일본어판 로고 (사용자 편집): Sonic World Adventure, 왼쪽 정렬한 한글 상단 문구와 획을 따른 외부 광선.

## 영어가 남아 보인다면

퀘스트 문구와 지명·버튼 그림은 별도 자료입니다. 다른 UI 모드가 그림만 덮어쓸 수 있으므로, 한패를 위에 두고 호환 옵션·DLC 설정·이전 한패 중복 설치를 확인하세요.

갤러리 영상 제목 272칸은 번역 파일과 일치합니다. 간헐적 영문 제목 제보는 아직 재현하지 못했습니다. 문제가 생기면 한패만 켠 경우와 비교하고, 영상 제목·모드 목록·순서를 기록해 주세요. 음악 감상 메뉴의 공식 영문 곡명은 영상 제목 번역 누락과 다릅니다.
