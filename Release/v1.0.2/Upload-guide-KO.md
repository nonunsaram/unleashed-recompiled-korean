# GameBanana v1.0.2 업로드 안내

기존 한국어 패치 페이지 https://gamebanana.com/mods/715787 에 업데이트합니다.

1. `UnleashedRecompiled-Korean-1.0.2-Basic.zip`과 `UnleashedRecompiled-Korean-1.0.2-Full.zip`을 그대로 업로드합니다. 다시 압축하지 마세요.
2. 파일 설명을 각각 `v1.0.2 Basic — HMM 기본판`, `v1.0.2 Full — Basic 포함, EXE UI 추가 한국어화`로 구분합니다. Basic을 기본 HMM 원클릭 설치 파일로 지정합니다.
3. 업데이트 제목은 `v1.0.2 — 로고 선택·UnleasHD 호환·번역 수정`을 사용하고 `GameBanana-update.md`의 내용을 업데이트 본문에 붙여 넣습니다.
4. 메인 소개문도 갱신하려면 `GameBanana-post.md`를 사용합니다. 모드 순서와 로고 선택 방법이 포함되어 있습니다.
5. 업로드된 ZIP을 다시 내려받아 `SHA256SUMS.txt`와 비교합니다.

이번 폴더의 두 ZIP이 최종 검증본입니다. 과거 개발용 압축본은 `outputs/Archive`로 옮겨 구분했습니다. GitHub에는 소스·설명서·체크섬을 올리고 배포 ZIP은 GameBanana에만 게시합니다.
