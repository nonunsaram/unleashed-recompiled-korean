# v1.0.2 로고·모드 호환 검토 (개발 중)

2026-09-13 복구 후 갱신. 이후 사용자 요청으로 검토 PC의 HMM에 개발본과 HRT, UnleasHD를 설치했습니다. 배포 ZIP 생성과 외부 게시는 보류합니다.
검토용 모드: `Build/Development-v102/UnleashedKorean`.
기존 `outputs/GameBanana-1.0.2`는 이번 로고·설정 수정 전 산출물이므로 현재 개발본과 구분해야 합니다.

## 로고

- `게임 기본값`, `영어판 로고 (소닉 언리시드)`, `일본어판 로고 (소닉 월드 어드벤처)`, `일본어판 로고 (사용자 편집)` 선택지를 추가했습니다.
- Recompiled 소스의 `UseAlternateTitleMidAsmHook`는 원본 디스크 지역이 아니라 표시 언어와 Alternate Title 코드로 로고를 고릅니다. 영어 표시 언어에서는 기본적으로 Unleashed가 나옵니다.
- 영어판·일본어판 선택형 `+Title`에는 `ui_title.yncp`만 넣었습니다. 사용자 편집형에는 글자 시트와 발광 시트도 포함합니다. 원본의 두 타이틀 장면 참조를 선택한 장면으로 연결하므로 별도 언어 변경이 필요 없습니다. 메뉴·음성 데이터는 이 파일에 추가하지 않습니다.
- 원본 장면 포인터 외 바이트 불변, 두 장면의 로고 캐스트 일치, 아카이브 재추출 후 바이트 일치를 검사했습니다. 실제 게임 화면은 추가 확인이 필요합니다.
- 원본 편집 자료는 `outputs/TitleLogo-v102-Editing`에 있습니다. `mat_title_001-original.png`는 1024×512 전체 시트, `txt_KANA-original.png`는 상단 가타카나 404×27 조각입니다. PNG는 DDS를 디코딩한 원본이며 AI 보정은 하지 않았습니다.
- 사용자가 제공한 404×27 투명 PNG의 「소닉 월드 어드벤처」를 상단에 적용했습니다. 원본은 `Assets/TitleLogo/CustomLogo.png`에 보존합니다. RGBA DDS로 저장하여 문구 영역 외 픽셀과 투명도를 그대로 유지한 것을 검증했습니다.

## 호환 옵션 저장 오류 수정

기존 v1.0.2 생성 코드가 `IncludeDir2`를 ConfigSchema의 `Compatibility` 그룹에 넣었습니다.
HMM은 그룹 이름을 INI 섹션으로 사용하므로 선택 결과가 `[Compatibility]`에 저장되지만, 게임은 `[Main]`만 읽습니다.
설정 항목을 `[Main]`으로 이동했고 이미 잘못 저장된 선택값도 이관합니다.
HMM의 실제 `ModConfig.Load/Save`와 `Ini` 소스로 DLC 7종 × 호환 2종 × 로고 4종, 총 56조합의 저장·재읽기를 검사했습니다.
이 결함은 **개발 중인 v1.0.2 옵션의 문제**이며, v1.0.1 사용자 제보의 직접 원인으로 소급하지 않습니다.

스파고니아·샤마르 연구실의 `MediaRoomJP_list.fco`와 `MediaRoom_list.fco`, 총 네 문구표에서 그룹 201~268의 영상 제목 272칸을 현재 한국어 카탈로그와 대조했습니다. 모두 일치합니다(공백·줄바꿈 차이는 무시).
홀로스카 영상의 266·267번 칸은 같은 번역 키를 공유합니다. 68칸을 68개의 고유 번역으로 가정한 검증 입력 생성기를 수정했습니다. 실제 번역 누락은 아니었습니다.
음악 감상 메뉴의 공식 영문 곡명은 기존 번역 방침이며 영상 제목 누락과 구분해야 합니다.
현재 자료만으로 사용자가 말한 간헐적 누락을 재현하거나 모드 충돌로 확정할 수 없습니다.

## 월드맵·버튼 영어 제보

첨부 화면에서는 퀘스트 문구가 한국어이므로 한패 전체가 비활성화된 상황과 다릅니다.
`Cool Edge`는 `mat_worldmap_en_002.dds`, 하단 안내는 `mat_comon_en_001.dds` 등 UI 이미지에 들어 있고, FCO 문구표와 별도로 교체됩니다.
개발본에는 한국어 버튼 이미지와 DLC별 월드맵 리소스가 있습니다. 추가 Full EXE 설치 여부만으로 두 이미지의 영문 잔존을 설명할 수 없습니다.
이전 조사에서 UnleasHD의 영어 월드맵 이미지 중복은 확인됐고 2배 해상도 호환 리소스를 준비했습니다. 이번 두 조사본에서 동일한 충돌은 확인되지 않았습니다.
가능성은 다른 UI/HUD 교체 모드의 우선 적용, 예전 패치 파일 혼용, 잘못된 DLC 구성입니다. 정확한 사용자 모드 목록·버전·순서가 없으므로 가능성을 원인으로 단정하지 않습니다.

## 사용자 인게임 검토

1. 검토용 모드를 사용하고 이전 한국어 패치와 동시에 켜지 않은 상태에서, 게임을 재시작하여 로고 네 선택지를 확인합니다. 일본어판 상단 문구·발광·등장 애니메이션·메뉴 위치를 확인합니다.
2. 한패만 켠 상태에서 홀로스카 월드맵 `쿨 에지`와 선택/뒤로 안내를 확인합니다. 설치한 DLC에 맞는 옵션을 사용합니다.
3. High Resolution Textures와 Visual Overhaul을 하나씩 추가하고 같은 화면을 확인합니다. UnleasHD를 쓰면 호환 옵션과 한패 우선순위를 함께 확인합니다.
4. 두 연구실의 이벤트 갤러리를 확인합니다. 특정 제목이 영어라면 연구실 위치, 영상 제목, 발생 전 이동/재생 순서와 당시 모드 목록·버전·순서를 기록하면 재현 범위를 좁힐 수 있습니다.
5. 사용자 편집 로고의 한글 문구가 타이틀 등장 애니메이션과 발광 효과에서도 자연스럽게 표시되는지 확인하고, 추가 버그 수집이 끝난 시점에 패키징합니다.

## 사용자 검토 이후 보완

사용자 스크린샷으로 mat_title_004.dds에 기존 일본어 글자 윤곽의 흰 발광이 남아 있음을 확인했습니다. 선택하신 매끈한 흰 받침을 좌상단 384×44 범위에 만들고 원래 지구·로고 몸체 발광과 연결했습니다. 범위 밖 픽셀, 사용자 글자 원본과 관련 없는 로고 시트, 장면 애니메이션 데이터 보존 및 아카이브 재추출 일치를 검사했습니다. 새 발광의 인게임 등장은 아직 미확인입니다.

UnleasHD 1.4.2 1440p ZIP의 게시 MD5와 크기를 확인하고 861개 파일을 CRC 검사하며 설치했습니다. 설치본 전체 SHA-256 대조도 통과했습니다. 한패의 UnleasHD 호환을 켰으며, HMM 활성 목록은 유지했습니다. [쉬운 설명·모드 순서·검토 방법](MODS-KO.md)을 함께 참고하세요.

## 후광 사각형 돌출 수정

사용자의 후속 스크린샷에서 오른쪽 흰 사각형과 왼쪽 수평 돌출이 확인됐습니다. 이전 생성 코드는 발광 텍스처를 일반 투명 그림으로 잘못 해석했습니다. 실제 원본 mat_title_004.dds는 모든 알파가 255이고 RGB 밝기로 후광을 표현합니다. 이전 코드는 수정 영역의 RGB를 모두 255로 쓴 뒤 알파를 바꾸었고, 특히 지구 보존 구간에서 원본 알파 255를 취해 흰 사각형을 만들었습니다. 이전 투명도 중심의 검사는 이 표현 방식의 오류를 놓쳤습니다.

수정본은 RGB 밝기를 수정하고 알파 255를 그대로 유지합니다. 좌상단 384×64 안에서 매끈한 받침을 원래 지구·본체와 연결하고, 교차 혼합으로 남던 일본어 글자 틈도 제거했습니다. 범위 밖 픽셀과 사용자 글자 원본은 그대로입니다. 새 검사로 이전 파일이 실패함을 확인했으며, 돌출 위치의 RGB가 어둡고 받침 내부가 균일하며 경계 밝기가 부드럽게 변하는지 검사했습니다. 밝기 미리보기에서도 양쪽 돌출과 얼룩이 제거됐습니다.

검토 PC의 HMM 사용자 편집 로고에 새 파일을 반영했습니다. 기존 설정과 모드 순서는 보존했습니다. 현재 실행 중인 게임에는 완전히 종료 후 다시 실행해야 적용됩니다. 새 빌드의 인게임 애니메이션 확인은 남아 있습니다. 검사 기록은 halo-fix-verification.json입니다.

## 왼쪽 정렬안 적용

사용자가 2번 안을 선택하여 한글 문구를 SONIC의 S 위쪽으로 옮기고 후광을 문구 폭으로 줄였습니다. 사용자 원본은 그대로 보존하고 404×27 스프라이트 안의 글자만 왼쪽으로 80픽셀 이동했습니다. 글자 크기·픽셀·등장 애니메이션 데이터는 유지합니다. 후광은 RGB 밝기 형식을 유지하며, 예전 일본어 문구가 있던 빈 부분은 SONIC·지구 조각의 원래 배치와 투명 윤곽으로 다시 구성했습니다. 본체와 연결하는 보정 범위는 후광 시트 좌상단 420×72입니다.

정지 배치 미리보기에서 왼쪽 정렬과 짧은 받침을 확인했고, 글자 픽셀 일치·수정 범위 밖 보존·불필요한 오른쪽 발광 제거·아카이브 재추출 검사를 통과했습니다. HMM의 사용자 편집 로고에 적용했으며 설정·모드 순서는 유지했습니다. 직전 중앙 정렬본은 Build/TitleLogoLeft-v102-*에 보관합니다. 실제 게임은 재실행 후 확인해야 하며, 배포 패키징은 보류합니다.

## 글자 획을 따른 외부 광선

사용자 제공 원문 화면과 Wii 표지의 의도에 맞춰 사각형 받침을 없앴습니다. 승인된 왼쪽 정렬과 글자 크기는 유지하고, 실제 한글 알파에서 2픽셀 확장·2.25픽셀 블러를 적용한 외부 광선을 생성합니다. 후광은 기존처럼 RGB 밝기로 저장하며 알파는 255를 유지합니다.

직전 왼쪽 정렬본과 글자 시트 및 장면 파일이 바이트 단위로 같은 것을 확인했습니다. 새 검사에서 이전 사각형이 거부되고 획을 따른 밝기 변화와 부드러운 감쇠를 확인했습니다. 정지 배치 미리보기를 검토한 뒤 HMM에 적용했습니다. 당시 일판 원본이 선택되어 있어 사용자 편집 로고로 되돌렸으며, 모드 순서와 다른 옵션은 보존했습니다. 실제 게임은 재실행 후 확인해야 하고 배포 패키징은 보류합니다.

## 외부 광선 강도 보완

사용자의 원본 일본어 로고 참조 요청에 따라 글자 획 확장을 2→3픽셀로, 밝기 배율을 1.0→1.3으로 올렸습니다. 블러 2.25픽셀과 왼쪽 정렬·글자 크기는 유지했습니다. 일본어 원본 후광과 밝기를 비교하고 강화 전후 정지 미리보기를 확인한 뒤 HMM에 적용했습니다. 글자 시트·애니메이션 파일 불변, 후광의 획 형태·암부·투명도 검사 모두 통과했습니다. 게임 재실행 후의 실제 모습은 사용자 확인이 남아 있으며 패키징은 보류합니다.
