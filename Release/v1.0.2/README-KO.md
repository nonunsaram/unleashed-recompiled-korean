# 한국어 패치 v1.0.2 — Full

Unleashed Recompiled v1.0.3 Windows x64용입니다. Full에는 Basic의 내용이 모두 포함되어 있으므로 두 판을 함께 설치하지 마세요.

1. 게임을 최소 한 번 실행해 초기 설정을 완료합니다.
2. Full ZIP을 HMM에 설치하고 게임을 종료합니다.
3. 모드 폴더의 `KoreanFullSetup.exe`를 실행하여 게임의 `UnleashedRecomp.exe`에 **.exe 한국어화 적용**을 누릅니다.
4. HMM에서 한국어 패치를 체크하고 저장합니다. 화면 언어는 English, 자막은 켜기로 설정합니다.

v1.0.1 Full에서 갱신할 때는 EXE 번역 내용이 같으므로 원본 복원이 필요 없습니다. v1.0.0 Full에서 바로 갱신한다면 이전 v1.0.0 도구로 먼저 원본 복원을 실행하세요. Basic은 EXE 설치 도구가 필요 없습니다.

UnleasHD 1.4.2를 함께 쓰면 HMM에서 한국어 패치 설정을 열고 **UnleasHD 호환 → UnleasHD 1.4.2**를 선택하세요. 한국어 패치를 UnleasHD보다 위에 두고 저장한 뒤 게임을 다시 시작합니다. 이 옵션은 UnleasHD의 2배 해상도 월드맵 지명·스테이지명 텍스처를 한국어판으로 교체합니다. UnleasHD를 쓰지 않으면 기본값인 사용 안 함을 유지하세요.

Crimson Carnival over Eggmanland와 Windmill Isle Act 5는 새 액트명 표를 자체 FCO로 추가합니다. 이번 UnleasHD 호환 옵션은 이 두 모드의 추가 액트명을 번역하지 않습니다.

모든 DLC가 설치되어 있으면 기본 DLC 설정을 사용합니다. 일부만 설치했다면 모드 설정에서 설치된 팩 중 목록의 가장 위 항목을 고르고, DLC가 없으면 `DLC 없음`을 선택하세요.

제거하거나 Basic으로 전환할 때는 Full 도구의 **.exe 원본 복원**을 먼저 실행한 뒤 HMM에서 해제하세요. `korean-native-backup`은 복원에 필요합니다. 게임·DLC·완성된 게임 EXE/XEX는 포함하지 않습니다.
