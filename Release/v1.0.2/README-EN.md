# Korean Translation v1.0.2 — Full

For Unleashed Recompiled v1.0.3 Windows x64. Full already contains Basic; install only one edition.

Run the game once to finish initial setup, install Full through HMM, close the game, and run `KoreanFullSetup.exe` from the mod folder. Select the game's `UnleashedRecomp.exe` and apply the EXE translation. Enable the mod, choose English text, and enable subtitles.

The translated EXE is unchanged from v1.0.1, so v1.0.1 Full users can update without restoring it first. Users upgrading directly from v1.0.0 Full must restore with the old v1.0.0 utility first. Basic does not use the EXE utility.

For UnleasHD 1.4.2, open the Korean patch configuration in HMM, set **UnleasHD compatibility** to **UnleasHD 1.4.2**, and place the Korean patch above UnleasHD. Leave this option disabled when UnleasHD is not installed.

The added act-name tables from Crimson Carnival over Eggmanland and Windmill Isle Act 5 are outside this compatibility option. Restore the EXE before removing Full or switching to Basic. No game, DLC, completed EXE, or XEX is included.

## Title logo and mod priority

Select the title logo in the Korean patch settings. The user-edited Japanese logo includes a left-aligned Korean caption. The default follows the game.

Recommended HMM order, top to bottom: Korean Translation, UnleasHD (1440p), Visual Overhaul – Characters, High Resolution Textures. Top entries have priority. All four were enabled together in a user gameplay test; this is not exhaustive coverage of every stage and configuration.
