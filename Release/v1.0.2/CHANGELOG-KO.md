# v1.0.2 변경 기록

- `에그 드래군`을 `에그 드라군`으로 바로잡고 용어집의 금지 표기도 반대로 수정했습니다.
- 자막 생성기의 대소문자 비구분 사전을 대소문자 구분 사전으로 교체했습니다. 이전 빌드의 `ExcEllEnt!` 현상을 실제 FCO/FTE와 글꼴 아틀라스에서 재현하고 수정했습니다.
- UnleasHD 1.4.2의 `+WorldMap`을 직접 조사했습니다. 충돌 원인은 메시지 파일이 아니라 영어 지명이 구워진 2배 해상도 DDS 두 장이었습니다. 같은 해상도에서 한국어 지명을 다시 렌더링한 선택형 호환 아카이브를 추가했습니다.
- Crimson Carnival over Eggmanland 1.1과 Windmill Isle Act 5 1.1도 직접 조사했습니다. 두 모드는 새 액트명 FCO를 통째로 제공하므로 단순 텍스처 호환으로 해결할 수 없으며, 이번 버전에는 포함하지 않았습니다.
- v1.0.1과 EXE 번역 내용은 동일합니다. v1.0.1 Full 사용자는 EXE를 복원하지 않고 v1.0.2로 갱신할 수 있습니다.
