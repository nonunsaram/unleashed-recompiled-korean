# 1.0.5 변경 내역

- **UnleasHD 모드의 모든 에셋을 제외했습니다.** UnleasHD 원본 이미지와 이를 수정한 파생 이미지를 모두 제거하고, 게임 원본과 직접 만든 한국어 자료로 교체했습니다.
- **권장 모드 구성 및 HMM 순서는 한국어 패치 → UnleasHD (1440p)입니다.** UnleasHD는 별도 설치하는 선택 모드입니다.
- 기본 한국어 UI와 독립 업스케일 한국어 UI를 선택할 수 있습니다. 업스케일 한국어 UI는 UnleasHD 없이도 작동합니다.
- 한국어가 들어가는 이미지만 게임 원본 기반 anime 업스케일 또는 자체 글꼴 렌더링으로 개선했습니다. 완성된 한글 글꼴·자막은 다시 AI 처리하지 않았습니다.
- 타이틀의 PRESS START, SEGA·저작권 표시와 NEW 표시를 다듬고, 한국어 로고 발광의 가장자리를 정리했습니다.
- HMM 기본 UI·게임 기본 로고 옵션의 경로가 배포 ZIP에서도 유지되도록 수정했습니다.
- DLC·로고·업스케일 옵션 설명과 설치 안내를 현재 구성에 맞게 정리했습니다.
- UnleasHD 병행 구성 및 UnleasHD를 끈 상태의 독립 업스케일 한국어 UI에 대한 사용자 인게임 확인을 완료했습니다.

기본판/전체판 구분은 유지됩니다. 전체판 EXE 한국어화 지원 대상은 공식 Windows x64 v1.0.3입니다.
