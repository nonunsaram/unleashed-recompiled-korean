# 한국어 패치 v1.0.3 — Full

Unleashed Recompiled v1.0.3 Windows x64용입니다. Full에는 Basic의 내용이 모두 들어 있으므로 둘을 함께 설치하지 마세요.

1. 게임을 한 번 실행해 초기 설정을 완료합니다.
2. Full ZIP을 HMM에 설치하고 게임을 종료합니다.
3. 모드 폴더의 `KoreanFullSetup.exe`를 실행해 `UnleashedRecomp.exe`를 선택하고 **.exe 한국어화 적용**을 누릅니다.
4. HMM에서 한국어 패치를 체크하고 저장합니다. 화면 언어는 English, 자막은 켜기로 설정합니다.

모든 DLC가 설치되어 있다면 기본 설정을 유지하세요. 기본값은 전체 DLC / UnleasHD 호환 사용 안 함 / 게임 기본 타이틀 로고입니다. UnleasHD 1.4.2를 함께 사용하면 한국어 패치를 UnleasHD보다 위에 두고 **UnleasHD 호환 → UnleasHD 1.4.2**를 선택하세요.

제거하거나 Basic으로 전환할 때는 Full 도구에서 **.exe 원본 복원**을 먼저 실행한 뒤 HMM에서 모드를 해제하세요. `korean-native-backup` 폴더는 복원에 필요합니다.

## v1.0.3 변경 사항

대사 줄바꿈, 돈 파치오 대사, 웨어혹 STRENGTH 레벨 업 표기를 수정했습니다. 소닉 언리쉬드 한국어 로고 시험본은 포함하지 않았습니다.
