# 그래픽 모드와 함께 사용하기

HMM의 위에서 아래 순서로 한국어 패치를 가장 위에 두세요.

1. Korean Translation / 한국어 패치
2. UnleasHD (1440p)
3. Sonic Unleashed Visual Overhaul – Characters
4. High Resolution Textures

UnleasHD 1.4.2를 사용하면 한국어 패치의 설정에서 **UnleasHD 호환 → UnleasHD 1.4.2**를 선택하세요. 저장한 뒤 게임을 완전히 종료하고 다시 실행합니다. 그래픽 모드는 이 한국어 패치에 포함되지 않습니다.
