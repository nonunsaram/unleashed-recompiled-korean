# 한국어 패치 v1.0.3 업데이트

- 대사창 밖으로 나갈 수 있던 일반 대사·힌트·핫도그 대사를 다시 검토해 줄바꿈을 정리했습니다.
- 돈 파치오 상점의 지역 대화와 미션 보상 대사를 원문에 다시 대조해 다듬었습니다.
- 웨어혹의 레벨 업 알림 상태 표기를 `ATTACK`에서 `STRENGTH`로 통일했습니다.
- HMM의 로고 선택 이름과 설명을 정리했습니다. 한국어 문구 로고는 **소닉 월드 어드벤처 (한국어 편집)**입니다.

실험했던 소닉 언리쉬드 한국어 로고는 이번 배포판에서 제외했습니다.

Basic과 Full 중 하나만 설치하세요. 전체 DLC를 사용한다면 모드 설정 기본값을 유지하면 됩니다. UnleasHD 1.4.2를 같이 사용하면 한국어 패치를 위에 두고 **UnleasHD 호환 → UnleasHD 1.4.2**를 선택하세요.

이번 버전은 21개 대사 아카이브와 56개 HMM 설정 조합을 구조적으로 검사했습니다. 실제 게임 플레이로 수정 장면을 확인한 것은 아니므로, 칩 힌트·보스 귀환·돈 파치오 대사·웨어혹 STRENGTH 레벨 업에서 표시 문제가 보이면 화면과 지역·미션 이름을 알려 주세요.
