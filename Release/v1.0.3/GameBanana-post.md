# Unleashed Recompiled 한국어 패치 v1.0.3

Unleashed Recompiled v1.0.3 Windows x64용 비공식 한국어 패치입니다. 게임 본편·업데이트·DLC는 포함하지 않습니다.

## 설치

Basic 또는 Full 중 하나를 HedgeModManager에 설치하고 한국어 패치를 활성화하세요. 게임 화면 언어는 **English**, 자막은 **켜기**로 설정합니다. Basic은 모드 리소스만 적용합니다. Full에는 Basic 내용과 EXE UI 한국어화 설치 도구가 함께 들어 있습니다.

모든 DLC가 설치되어 있다면 기본값을 유지하세요. 일부 DLC만 설치했다면 HMM의 모드 설정에서 설치한 팩 중 가장 위의 항목을 선택하고, DLC가 없다면 `DLC 없음`을 선택하세요.

UnleasHD 1.4.2를 함께 사용하면 한국어 패치를 UnleasHD보다 위에 둔 뒤 **UnleasHD 호환 → UnleasHD 1.4.2**를 선택하세요.

타이틀 로고는 모드 설정의 **타이틀 로고**에서 바꿀 수 있습니다. 한국어 문구 로고의 이름은 **소닉 월드 어드벤처 (한국어 편집)**입니다.

## v1.0.3

대사창 줄바꿈, 돈 파치오 대사, 웨어혹 STRENGTH 레벨 업 표기를 다듬었습니다. 실험했던 소닉 언리쉬드 한국어 로고는 배포에 포함하지 않았습니다.
