# 한국어 패치 v1.0.3 업데이트

## 변경 사항

- 일반 NPC·힌트·핫도그 대사 381항목을 다시 검토했습니다. 이 중 253항목은 이전 수정본의 줄바꿈을 다시 다듬었으며, 2항목은 뜻을 유지한 채 짧게 정리했습니다.
- 돈 파치오 상점의 지역 대화, 미션 시작·완료·보상 대사를 일본어와 영어에 대조해 문장 순서와 표현을 보완했습니다.
- 웨어혹의 레벨 업 알림 상태 표기를 `ATTACK`에서 `STRENGTH`로 통일했습니다.
- HMM 설정의 로고 선택 이름과 설명을 정리했습니다. 한국어 문구 로고는 **소닉 월드 어드벤처 (한국어 편집)**입니다.
- 실험했던 소닉 언리쉬드 한국어 로고는 선택지·활성 리소스·배포 파일에 포함하지 않았습니다.

## 설치와 호환

Basic과 Full 중 하나만 설치하세요. 게임 화면 언어는 **English**, 자막은 **켜기**로 설정합니다.

모든 DLC를 설치했다면 HMM 모드 설정의 기본값을 그대로 사용하세요. 기본값은 전체 DLC / UnleasHD 호환 사용 안 함 / 게임 기본 타이틀 로고입니다. UnleasHD 1.4.2를 사용할 때는 한국어 패치를 UnleasHD보다 위에 두고 **UnleasHD 호환 → UnleasHD 1.4.2**를 선택한 뒤 게임을 다시 시작하세요.

## 검증 범위

대사 아카이브 21개와 리소스 파일 42개를 재직렬화·재추출해 대조했습니다. HMM 설정의 DLC 7종, 호환 2종, 로고 4종 조합 56가지를 저장·재읽기 검사했습니다. 실제 게임 플레이로 이번 수정 장면을 확인한 것은 아닙니다.

확인하면 좋은 장면은 칩 힌트, 보스 귀환 대사, 돈 파치오 미션 전후 대사, 웨어혹 STRENGTH 레벨 업입니다.
