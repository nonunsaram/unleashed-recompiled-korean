# Korean Translation 1.0.3 — Full

For Unleashed Recompiled v1.0.3 Windows x64. Full includes Basic, so install only one edition. Install the ZIP with HedgeModManager, then run `KoreanFullSetup.exe` in the mod folder to apply executable-based UI translation. Select English text and enable subtitles in game.

All DLC installed: keep the default configuration. The defaults are All DLC, no UnleasHD compatibility, and the game default title logo. For UnleasHD 1.4.2, put the Korean patch above UnleasHD and select **UnleasHD compatibility → UnleasHD 1.4.2**.

Before uninstalling Full or switching to Basic, restore the executable with the Full setup tool. Keep `korean-native-backup` for restoration.

## v1.0.3 changes

Refined dialogue line breaks, Don Paquio dialogue, and the Werehog `STRENGTH` level-up label. The experimental Korean Sonic Unleashed title logo is not included.
