# GameBanana v1.0.3 업로드 안내

기존 한국어 패치 페이지 https://gamebanana.com/mods/715787 에 업데이트합니다.

1. `UnleashedRecompiled-Korean-1.0.3-Basic.zip`과 `UnleashedRecompiled-Korean-1.0.3-Full.zip`을 그대로 업로드합니다. 다시 압축하지 마세요.
2. 파일 설명은 각각 `v1.0.3 Basic — HMM 기본판`, `v1.0.3 Full — Basic 포함, EXE UI 추가 한국어화`로 적습니다. Basic을 기본 HMM 원클릭 설치 파일로 지정합니다.
3. 업데이트 제목은 `v1.0.3 — 대사 줄바꿈·돈 파치오·STRENGTH 수정`을 사용하고 `GameBanana-update.md`를 업데이트 본문에 붙여 넣습니다.
4. 메인 소개문을 바꿀 때는 `GameBanana-post.md`를 사용합니다.
5. 업로드한 ZIP을 다시 내려받아 `SHA256SUMS.txt`와 비교합니다.

GitHub에는 소스·문서·체크섬만 올리고, 배포 ZIP은 GameBanana에만 올립니다.
