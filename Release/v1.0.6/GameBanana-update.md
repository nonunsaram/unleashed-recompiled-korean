# 1.0.6 설치기 수정판 — 2026-10-04

- 1.0.5 Full의 내장 manifest가 review16 버전에 머물러 적용을 막던 오류를 수정했습니다.
- 설치기와 외부 manifest의 원시바이트 일치를 패키징 전 및 최종 ZIP에서 필수 검사합니다.
- 1.0.0, 초기 1.0.1, 검토된 1.0.1~1.0.5 EXE를 해시로 식별하고 검증된 원본 백업을 통해 최신 EXE를 적용합니다.
- 1.0.0의 번역된 default.xex는 검증된 원본 백업으로 함께 복원합니다. 두 파일 교체 실패 시 작업 전 상태로 롤백합니다.
- 원본 백업 누락·손상, 미상 EXE, 1.0.0의 미상/누락 XEX는 파일 변경 없이 중단합니다. 백업 없는 강제 복원·역패치는 지원하지 않습니다.
- 게임 그래픽·번역 자산과 최신 EXE 패치 데이터는 1.0.5와 같습니다. 사용자 설정·음성 언어·다른 모드·세이브를 변경하지 않습니다.
- Basic은 설치기를 포함하지 않습니다. Basic도 배포 버전과 문서를 1.0.6으로 통일했습니다.
- 1.0.6 검증은 격리된 복사본에서 진행하며 실제 게임 실행 검증은 새로 수행하지 않았습니다.

설치: 기존 Full 폴더에 파일을 혼합하지 말고 새 1.0.6 ZIP을 별도 폴더에 압축 해제합니다. 게임을 종료한 뒤 새 KoreanFullSetup.exe에서 게임 EXE를 선택하여 적용합니다. 기존 korean-native-backup 폴더는 보존하세요. 1.0.0에서 전환할 때 EXE와 XEX 원본 백업이 모두 필요합니다.
